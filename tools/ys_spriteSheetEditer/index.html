スプライトシートエディタ

すすめ！ゆうしゃ のキャラの絵（sprites.png）を、入れかえたり描きなおしたりして、ゲームに反映します。

キャラ

画像をはなすと このセルに入れかえ

絵は右向きで描きます。足もとをセルの下の端に、体を左右の真ん中に合わせると、ゲームでの立ち位置がずれません。左向きと、当たったときの白い絵はゲームが作ります。

プレビュー

左が右向き、右が左向き（ゲームと同じ大きさの2倍）。歩きの2コマは交互に動きます。

いま描いているシートで、ゲームを別のタブで開きます（このブラウザの中だけ。保存はされません）。

保存

書き出した sprites.png を、リポジトリの games/Susume-Yusha/ に置きかえて上げると、ゲームに反映されます。

GitHub に直接保存する
このブラウザにトークンを覚えておく

保存すると main にコミットされ、GitHub Pages の更新（1分ほど）のあとゲームに反映されます。トークンはこのブラウザから GitHub にだけ送ります。
