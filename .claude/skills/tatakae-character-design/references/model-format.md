# 箱モデルのコードの書き方

モデルは `games/Tatakae-Yusha/src/render2d.js` にある関数が、**部品のリスト**を返す形です。Canvas 2D の描画も、WebGL の描画(`src/three-chars.js` の `BoxModel`)も、同じリストを使います。

## 部品(1つの箱)

```js
const parts=[],B=(cx,cy,cz, sx,sy,sz, col, ops, bias)=>parts.push({c:[cx,cy,cz],s:[sx,sy,sz],col,ops:ops||[],bias:bias||0});
```

- `c` … 箱の中心 (x, y, z)。`s` … 大きさ (幅 x, 高さ y, 奥行き z)。`col` … `'#rrggbb'`。
- `ops` … 回転の列(下)。`bias` … 重なって見えるときの優先(顔の目・口は `0.02〜0.04`)。

## 座標

- 原点は**足もとの中心**(地面)。**前が `+z`**、上が `+y`。
- `x` は、キャラの左が `+x`、右が `-x`(勇者は右手の剣が `x = -0.38`)。
- 単位はゲームの長さ。勇者の高さが約 2.17。
- 向き: `yaw = 0` でカメラのほうを向く、`yaw = π` で奥(敵のほう)を向く(ゲームの通常の後ろ姿)。

## 回転 `ops`

```js
{t:'x'|'y'|'z', a:ラジアン, p:[x,y,z]}   // p を中心に、その軸で回す
```

- 列は**上から順に**適用される(各 `p` は、その時点の座標)。
- 関節はこれだけ: 足 = `p` をももの付け根(`[px, 0.6, 0]` など)に置いた `x` 回転。うで = 肩。
- 体をかたむける(`lean`)・ひねる(`twist`)・倒れる・ふっとぶ動きは、**足より上の全部品に、最後に `ops` を足す**形で作っている。そのため、**足の部品を最初に作り、`const legCount=parts.length` で数を控える**。
- ひじ・ひざはない(うで・足は1本の箱)。曲げたいときは、箱を2つにして別々に回すが、部品が増える。

例(足):

```js
for(const sx of [-1,1]){
  const px=sx*0.17, lp=[{t:'x',a:sx*sw,p:[px,0.52,0]}];     // sw: 歩きのふり
  B(px,0.34,0, 0.18,0.36,0.18, SKIN, lp);                  // 足
  B(px,0.08,0.07, 0.24,0.16,0.40, SHOE, lp);               // くつ
}
```

## 関数の型

| 関数 | 引数 | 返すもの |
|---|---|---|
| `heroParts(h)` | `h` = 勇者の状態(`S.hero`) | `{parts, yaw}` |
| `allyParts(yaw, mv, ph, cast, fire, down)` | 向き・歩きの強さ・歩きの位相・詠唱のようす・炎の色・倒れの進み | `{parts, yaw}` |
| `enemyParts(eyeCol, tint, sc, yaw, mv, ph, atk, stag, dash)` | 目の色・はだの色・大きさ(`e.r`)・向き・歩き・予告中・よろけ・とっしん中 | `{parts, yaw, scale}` |

- 新しいキャラは、同じ形の `xxxParts(...)` を作り、`{parts, yaw}`(大きさを変えるなら `scale` も)を返す。
- 描くのは、2D は `drawXxx(x,y,s,...)` が `h3render(parts, x, y, s*scale, flash, yaw, 0)` を呼ぶ。WebGL は `three-chars.js` の `makeChars` の `update` で `BoxModel.set(parts, scale, flash)` を呼ぶ。**両方に足す**。
- 見た目の倍率(`scale`)は、**見た目だけ**。当たり判定は `CFG` の `r`(ロジック)で、変えない。

## 描画のしくみ(知っておくこと)

- 面の明るさは、**光の向き(左上手前)と面の向き**で決まる。色は面ごとに 0.52〜1.14 倍。
- 輪郭の線は、箱の12本のふちに、濃い紺で引く。WebGL では太い線(`LineSegments2`)で、**太さはモデルの大きさに合わせて変わる**(`lineScale`)。
- 面の奥行きの順は、箱の中心の奥行き + `bias` で決める。**薄い箱を表面にはる**ときは、箱の厚さを 0.015〜0.03 にして、`bias` を付ける(`0.02` 前後)。
- 半透明・テクスチャは使えない。

## 動きの入れ方(既存のものを参考に)

- 歩き: 足を `sx * sin(ph) * 0.75 * mv` で回す。体の上下は `bob`。
- 呼吸・ゆれ: `bob` と `lean` を、`sin(t*3)` などで少し動かす。
- ポーズの切りかえ: 状態の強さ(0〜1)を、`logic.js` の `step` でなめらかに変え(`h.pushK` など)、モデル関数で補間する。
- 倒れる・ふっとぶ: 全部品に `x` 回転を足し、必要なら `y` を持ち上げる(`heroParts` の最後の部分)。
- 見た目だけの状態(`pushK` `firmK` `swingV` `downT` など)は、**ロジックの結果に影響させない**(ボットの結果=勝敗・時間などが変わってしまう)。

## 部品の数の目安

| 部分 | 数 |
|---|---|
| あたま(かお・目・口・ほほ・まゆ) | 8〜12 |
| かみ・ぼうし | 8〜13 |
| からだ・服 | 6〜12 |
| うで(2本) | 4〜6 |
| 足・くつ | 6〜10 |
| もちもの(つえ・剣) | 4〜10 |
| 合計 | **80個以内**(標準 60〜70) |

## 新しいキャラを足す手順

1. `render2d.js` に `xxxParts(...)` を書く(`legCount` を足の直後に)。
2. 描き方を足す: 2D は `drawXxx`、WebGL は `three-chars.js`(`BoxModel(80)` の上限を確認)。
3. ロジック側にキャラを足すなら、`logic.js` の `init`(`S` にキャラを入れる)・`CFG`(`hp` `r` など)・`step`(動き)を、**別の依頼として**やる。デザインの依頼だけなら触らない。
4. `tools/sansmen.js` に三面図の設定を足して、`docs/xxx-3view.png` を作る。
5. ボットで、ゲームが最後まで動いてエラーが出ないことを確かめる(`node tools/bot.js --seeds 1`。2D表示との比較は、もうしない)。作業環境でCDNに接続できないときは、環境変数 `THREE_DIR` に `node_modules/three` を指定する。
