# 画像生成AIに渡す指示(貼れる文面)

「戦え！ゆうしゃ」のキャラを、画像生成AIに作ってもらうときの文面です。`【 】` の部分を、キャラに合わせて書きかえます。**絵の中に文字は入れない**(日本語や色コードが崩れるため)。色コードは、必ず**別の文章**で書きます。

## 共通の条件(毎回、先頭に付ける)

```
ゲーム用キャラクターの設定画を作ってください。次の条件を必ず守ってください。
- ローポリの箱(ボクセル)だけで構成する。すべての部品は直方体。曲面・斜めの面・丸・テクスチャは使わない。
  ふくらみや模様は、色の面で表す。
- 正投影(パースなし)。影なし、フラットな光。輪郭は濃い紺の細い線。
- 背景は無地(うすい方眼紙は可)。魔法のエフェクト、動きの線、キャラ以外の飾りは入れない。
- 絵の中に文字・数字・ロゴは入れない。
- 腕と脚は、ひじ・ひざで曲げない、まっすぐな棒状にする(動きは肩と脚の付け根だけで作るため)。
- 使う色は12色以内。色は別の文章の表のとおりに使う。
```

## A. 三面図(最初に頼む)

```
【キャラの説明: 例「どすこいオーガ」ふうの、つのとまわしがある大きな敵。相撲のモチーフ】

正面・側面・背面を、同じ高さ・同じ縮尺で、横1列に並べた三面図を1枚で作ってください。
- 直立の待機ポーズ。腕と脚は体から少し離す。
- 比率: 基準の人間キャラ(高さ100)に対して、このキャラの高さは【170】。
  頭の高さは全身の【1/4】。かたはば(とげ・かざりを除く)は高さの【0.5】。
- 固定の特徴(必ず入れる): 【つの2本、きば2本、かたのとげ、赤いまわし、大きなおなか】
- 左右対称にする(顔と体)。
- 三面図のそばに、基準の人間キャラ(勇者)を、同じ縮尺で小さく並べる。【参考画像として渡す】

【色の表を、ここに「名前・色コード・使う場所」で書く】
```

## B. 色ちがい(おもさ別の敵など)

```
添付の三面図と、同じ造形・同じ比率のまま、色だけを変えた版を作ってください。
- 形は一切変えない。箱の数・大きさも同じ。
- 色の表: 【かるい=みどり系 / おもい=茶色系 の色コードを、別の文章で書く】
```

## C. ポーズ(三面図ができてから)

```
添付の三面図のキャラを、造形・色・比率を保ったまま、次のポーズで描いてください。
- 【ポーズ: 例「両手を高くふりあげた攻撃の予告」「前かがみのとっしん」「あおむけに倒れた姿」】
- 正面からの1枚。パースなし。背景は無地。文字は入れない。
- 腕・脚は棒状のまま。体のかたむき・腕の角度だけで表す。
```

## D. 今のキャラの見た目だけを変える(デザイン変更)

```
添付の三面図(現在のゲームの形)の、比率と箱の数をそのまま保ち、デザインだけを次のように変えてください。
- 変える点: 【髪型をツインテールに / 色を紫に / ぼうしを大きく など】
- 変えない点: 【背たけ・頭の大きさ・体の幅・足の長さ・もちものの位置】
- 出力は、正面・側面・背面の三面図。条件は共通の条件に同じ。
```

## 画像を受け取ったら(Claude のほうで)

1. 絵から、**色を読み取って表にする**(色コード・使う場所)。AIが書いた色コードは信用しない。
2. 箱にできない点を洗い出し、置きかえを決める(SKILL.md の表)。
3. 高さ・頭の大きさ・かたはばを、絵から比率で読み取り、勇者(2.17)に対する値にする。
4. 箱モデルを作り、三面図(`tools/sansmen.js`)を作って、絵と並べて見比べ、差を報告する。
5. 差が大きいところは、画像AIに「ここだけ直して」と戻す指示(D の形)を作る。

## 依頼書のチェック(画像を頼む前に)

- [ ] 大きさ(勇者に対する比)と、頭・かたはばの比を、数字で書いた。
- [ ] 固定の特徴(見分けのつく3〜5点)を書いた。
- [ ] 色を12色以内で、色コード付きの表にした(別の文章)。
- [ ] 「文字を入れない」「パースなし」「箱だけ」「腕・脚はまっすぐ」を入れた。
- [ ] 今のキャラの三面図を、参考画像として渡した(デザイン変更のとき)。
