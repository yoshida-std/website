# すすめ！ゆうしゃ（`games/Susume-Yusha/`）

スーファミRPG風の絵で、勇者が右へ進む横スクロールアクション（プロトタイプ）。公開URL: `https://yoshida-std.github.io/website/games/Susume-Yusha/`
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/KEX8vTqyZ5X9F5ju5pqruJ`（変更のたびにこの URL を更新する。`index.html` と、`files` で `sprites.png`・`sprites.json`・`sound/bgm_field.mp3`・`sound/bgm_boss.mp3` を同じパスで載せる）

## 概要と操作

- スマホ横画面専用。縦向きのときは「よこむきに してね」を出して一時停止する（`#rotate`）
- 画面の左 1/3 が操作エリア（`#panel`: パーティ窓と円盤）、右 2/3 がゲーム画面（`#screen`）
- ゲーム画面は高さ 224 ドットの canvas をドットのまま拡大。幅 `W` は右 2/3 の比率で 256〜440 に変わる（`layout()`）。ベルトスクロール型で、地面に奥行き（`z`）がある
- 絵: キャラは `sprites.png` から読む（下の「キャラのグラフィックシート」）。背景（空・雲・山2層・森・草原）、木・岩・箱・スライムは起動時に `buildArt()` で手続き的に描いておく（`ART`, `SP`）。ほかのキャラは文字列のドット絵に `shade()` で陰をつけ、`scale2x()` でなめらかに2倍にする（キャラは32ドット前後）。ボスのドラゴン（108x98、2コマ）は `makeDragon()` で描く。当たり判定・剣の間合いもこの大きさに合わせてある
- 操作エリアの絵: 石の板・光るひび・ルーンの輪・鷲（`drawPanel`）、盾の円盤（`drawShield`）、鋼のつまみ（`drawKnob`）を canvas に画面の解像度で描く。`layout()` のたびに描き直す。窓は青グラデーション（CSS）
- 強制スクロール: カメラは `SCROLL`（40px/秒）で右へ進む。左右を入れていないとき（上下だけのときも）、勇者はスクロールと同じ速さで前へ歩く（ボス戦では止まる）。勇者は画面の左端に押され、そのときは障害物もすり抜ける
- スタート時は勇者が左の画面外から歩いて入ってくる（`G.intro`。その間は操作・スクロール・敵の出現なし）
- 移動の速さは左右 130、奥・手前 90（px/秒）。ジャンプの初速は 245（高さ約46ドット）
- 操作: 左の円盤（スティック）で上下左右（上下＝奥・手前）。中央のつまみを押して放すと、剣を振って三日月の斬撃を飛ばす（`castSlash`。基本12、0.35秒ごと）。長押しでため（`LV_T`: 0.5/1.0/1.6秒で1〜3段。ためられる段の上限は仲間の数 `maxLv()`。仲間がいないとためられない。仲間が加わるとメッセージで知らせる。段ごとに光の粒とつまみが 青→水色→金→赤 に変わり、音が鳴る）。放すと段に応じた大きな斬撃（`WAVE`: 基本 12/24/42/72）。1段以上の斬撃は敵をつらぬいて1体に1回ずつ当たり、敵の弾（魔法・ボスの火の玉）を消す。3段目は画面が揺れる。中央から始めたタッチは、そのまま指を動かせば、ためながら移動でき、放すと斬撃。矢印の上から始めたタッチは移動だけ。動かしながら別の指で円盤をタップしても斬撃。ジャンプボタンはない。円盤はタッチイベントで受け（`#panel` 全体。操作エリアの下側か円盤の円の中で始めたタッチ）、マウスはポインターイベント。PC は矢印/WASD、スペースで斬撃（長押しでため）
- パーティ窓（操作エリアの上、文字10px・HPバー5pxのコンパクトな窓）に HP と進み具合。一時停止ボタン（ひとやすみ）は画面の左上（操作エリアの一番上、パーティ窓の上）。ゲーム画面の右上は Claude アプリのボタンに隠れて押せないことがあるので置かない。ボタン（ひとやすみ・メニュー）は `onTap` で指を離したとき（touchend）にも動く（ホーム画面に追加した iOS アプリでは click が届かないことがあるため。click は二重にならないよう0.7秒は無視）。ひとやすみは押せる範囲を見た目より広くしてある（`::after`）。円盤は操作エリアの下側の空きに収まる大きさに合わせる（`fitStick`、ResizeObserver）。メッセージ窓はゲーム画面の上部（キャラが動けない空の部分）、ボスの HP はメッセージ窓の下の右側
- 自動ジャンプ: 進む先に穴か岩・箱があると、向こう側に届く速さで自動で跳ぶ（`autoJump`。跳んでいる間は踏み切ったときの速さ `hero.airV` で進む）。向こう側がない（木、地面の端まで続く穴）・着地点が画面の外になるときは跳ばずに手前で止まる
- 剣は自動。敵が `range` 以内に来ると振って、前方の敵をまとめて薙ぎ払う（`trySwing`）。敵の魔法（`shots` の `friend:false`）は剣では消えない。移動でよけるか、ためた斬撃で消す
- 穴はどれも、ジャンプしなくても通れる道（幅24以上）を残す（`HOLES`）。落ちると HP −20 で近くの安全な位置（`findSafe`）に戻る。岩・箱はジャンプでこえられる（上に乗れる）、木はこえられない
- 勇者の HP が 0 でゲームオーバー
- 道の途中で町の人（`MOB`: まちびと・こども・むすめ・しょうにん・へいし・おひめさま・おうさま。`MOB_SPOTS`）も魔物に襲われている（仲間と同じ `updNpcs`、`n.mob`）。助けると `G.followers` に入り、画面の左の最後列をスクロールに合わせて歩く（`updFollowers`）。ボス戦の間は画面の外へかくれ、勝ったら入ってきて勇者たちの後ろに並び、喜んで跳ねる。クリア画面に「たすけた ひと」を出す
- ボスをたおすと、勇者と仲間が順に小さく跳んで、正面を向いて剣や杖をかかげる決めポーズ（`CLS[].pose`。`POSE_HEAD`/`POSE_SWORD`/`POSE_STAFF`/`POSE_BODY` を重ねて作る）。勇者を真ん中に、画面の中央に横一列に並ぶ。約3秒後（町の人がいれば4秒後）にクリア画面

## 音

- BGM は音声ファイル: `sound/bgm_field.mp3`（道中、BGM031「力を出しきれ」32秒）と `sound/bgm_boss.mp3`（ボス、BGM084「燃やしつくすぜ」41.14秒）。ユーザーがくれた WAV を ffmpeg で 128kbps の MP3 にしたもの
- WebAudio でくり返し流す（`BGM_FILES`, `bgmFile`）。MP3 の頭の無音を飛ばし、もとの WAV の長さでくり返す（`loopPoints`）。遊んでいる・音 ON・画面が見えているときだけ流し（`syncBgm` を 50ms ごと）、一時停止では止めて続きから。ボスをたおしたら止める（`stopBgm`）
- 音声ファイルを読めないときは、前からある合成の BGM（`SONGS`）を鳴らす。効果音は合成（`SFX`）

## キャラのグラフィックシート

- `sprites.png`（ゲームが読むシート、透明の背景）と `sprites.json`（どの絵がシートのどこにあるか: `frames` の `名前: {x,y,w,h,s}`）。セルは「描くときの大きさ」で、ゲームは `s`（表示の倍率）に合わせて縮めて表示する（`shrink`: 面積の平均、ふちの半透明はなくす）。キャラ（勇者・仲間・町の人）は表示の 1.5 倍（48x48 → 32x32、s=2/3。ポーズ 48x66 → 32x44、こども 48x36 → 32x24）、敵・ドラゴンは表示の 2 倍（s=1/2。スライム 72x60 → 36x30、ドラゴン 216x196 → 108x98）。表示の大きさ・当たり判定はこれまでと同じ。起動時に読みこみ（`loadSheet`）、コードで描いた絵の代わりに使う。読めないとき・URL に `?nosheet` を付けたときはコードの絵のまま（`SHEET.loaded`）
- 名前: `char.{hero|warrior|mage|priest}.{0|1|pose}`（0・1 は歩きの2コマ）、`mob.{town|child|woman|merchant|soldier|princess|king}.{0|1}`、`enemy.{slime|bat|skel}.{0|1}`、`enemy.wiz.0`、`boss.dragon.{0|1}`
- 絵は右向き（左向きと、当たったときの白い絵はゲームが作る）。足もとがセルの下の端、左右の真ん中がキャラの立つ位置。剣・杖・槍・影はゲームが描く（決めポーズの剣・杖は絵に入っている）。絵に武器が入っているキャラは `sprites.json` の `weaponInSprite`（例 `["char.hero"]`）に書くと、ゲームは武器を重ねて描かず、振ったときの軌跡だけ描く
- 勇者はユーザーが用意した絵（64x64 を 48x48 のセルに縮めて入れたもの。表示は仲間と同じ 32x32。剣入り、決めポーズは親指を立てた正面向き）。`sprites.json` の `custom` に入れてあり、書き出しスクリプトで上書きされない。ほかのキャラはコードの絵（元のドットを Scale3x / 敵は Scale2x で大きくしたもの）
- 描きかえるときはセルの中だけを描く。セルの大きさを変えたら `sprites.json` の w,h も直す（当たり判定は変わらない）
- `sprites-guide.png` は名前と枠を書きこんだ見本（ゲームは読まない）
- `tools/export-sprites.js`: `node games/Susume-Yusha/tools/export-sprites.js` でコードの絵から描く大きさのシート・json・見本を作り直す（`custom` のコマはいまのシートの絵を使う。それ以外は描きかえていても上書き）。`--from-sheet` を付けると、いまのシートの絵をすべてそのまま使って並べなおし、見本も作り直す。`custom`・`weaponInSprite` は引きつぐ
- 木・岩・箱・背景はシートに入れていない（コードで描く）
- 専用エディタ（描く大きさのセルを編集。プレビューと表示の大きさはゲームと同じに縮めて見せる）: `tools/ys_spriteSheetEditer/`（公開URL `https://yoshida-std.github.io/website/tools/ys_spriteSheetEditer/`、確認用 Artifact `https://claude.ai/artifact/PLtp88E6JkvpB8jQ1p323j`。Artifact では書き出し・GitHub 保存・ゲームでためすは動かないので、本番は Pages で使う）。ゲームのシートを読み、コマを選んで画像の入れかえ（ドロップ・貼りつけ・ファイル。足もと下・左右中央に合わせ、大きければ縮める）とドットの描きなおし（ペン・消しゴム・スポイト・塗りつぶし・左右反転・元に戻す）ができる。プレビューで歩きの2コマを右向き・左向きで動かす
  - 「ゲームで ためす」: 描きかけのシートを localStorage（`susumeYusha.sheetPreview`）に入れ、ゲームを `?preview` で開く。ゲームはそのシートで動く（同じサイトの中だけ。保存はされない）
  - 保存: sprites.png の書き出し、または GitHub の Contents API で直接コミット（リポジトリ・ブランチ・場所・トークンを入れる。トークンは覚えさせたときだけ localStorage の `susumeYusha.ghToken`）。セルの大きさは変えないので sprites.json はそのまま

## 仲間

- `ALLY_SPOTS` の位置にいて、画面に入る前に魔物の群れ（`GUARDS`）に取りかこまれる（`updNpcs`。`state`: wait → captive → joined / lost）。群れを全部たおすと助けられて仲間になる（最大4人＝勇者＋3人）。助ける前に画面の左へ流れると `lost`（助けられない）
- 見張りの魔物は勇者が 96 以内に来るまで仲間のまわりを回って襲いかかる動き（`e.guard`, `e.aggro`）。とらわれた仲間はおびえて震える
- 仲間になると勇者のまわりの `SLOTS` についてくる
- せんし: 剣で自動攻撃（基本17）／まほうつかい: 近くの敵へ火の玉を撃つ／そうりょ: 4.5秒ごとに一番減っている仲間を回復
- 仲間も HP を持ち、0 になるといなくなる。穴の上は跳ねてわたる（落ちない）

## ダメージと命中演出

- HP と攻撃力は10倍の数値（スライム9・コウモリ8・ガイコツ30・まどうし20・ボス460。勇者の剣11・斬撃12・ためた斬撃24/42/72・せんし17・そうりょ6・火の玉8）。ダメージは基本値の ±15%、8% で会心（2倍）（`roll`）
- 当たると数字がとび出す（白、会心は黄色の大きな数字）。火花・斬撃の線・敵の震えを出し、剣のときは一瞬止める（`hitFx`, `G.hitstop`）。たおした敵はくるくる回りながら画面の外へ吹き飛び、出た所でキラッと光る（`launch`, `G.flyers`, `twinkle`）

## 敵とボス

- `ET`: slime（はねる）、bat（飛ぶ・穴に落ちない）、skel（HP3）、wiz（距離をとって魔法を撃つ）
- 右端から出てくる。進んだ距離（`G.camX`）ごとの群れと、時間ごとの1体。カメラが `END-W` に着くとカメラを止めてボス戦
- ボス「ほのおの ドラゴン」HP460。口から火の玉3発（HP半分以下で5発）と突進をくり返す。羽ばたきと手の炎は2コマで動く
