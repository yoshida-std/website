# すすめ！ゆうしゃ（`games/Susume-Yusha/`）

スーファミRPG風の絵で、勇者が右へ進む横スクロールアクション（プロトタイプ）。公開URL: `https://yoshida-std.github.io/website/games/Susume-Yusha/`
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/KEX8vTqyZ5X9F5ju5pqruJ`（変更のたびにこの URL を更新する。`index.html` 1枚だけ。音は WebAudio で鳴らすので音声ファイルはない）

## 概要と操作

- スマホ横画面専用。縦向きのときは「よこむきに してね」を出して一時停止する（`#rotate`）
- 画面の左 1/3 が操作エリア（`#panel`: パーティ窓と円盤）、右 2/3 がゲーム画面（`#screen`）
- ゲーム画面は高さ 224 ドットの canvas をドットのまま拡大。幅 `W` は右 2/3 の比率で 256〜440 に変わる（`layout()`）。ベルトスクロール型で、地面に奥行き（`z`）がある
- 絵: 背景（空・雲・山2層・森・草原）、木・岩・箱・スライムは起動時に `buildArt()` で手続き的に描いておく（`ART`, `SP`）。ほかのキャラは文字列のドット絵に `shade()` で陰をつける。窓は青グラデーション、円盤は金属風（CSS）
- 強制スクロール: カメラは `SCROLL`（30px/秒）で右へ進む。勇者は画面の左端に押され、そのときは障害物もすり抜ける
- 操作: 左の円盤（スティック）で上下左右（上下＝奥・手前）。円盤を短くタップ（260ms 未満・16px 未満）するとジャンプ。動かしながら別の指で円盤をタップしてもジャンプ。ジャンプ中に指を離していると、踏み切ったときの向きに進み続ける（`hero.air`）。PC は矢印/WASD とスペース
- パーティ窓（操作エリアの上）に HP と進み具合。メッセージ窓はゲーム画面の上部（キャラが動けない空の部分）。その右に一時停止、ボスの HP はメッセージ窓の下の右側
- 剣は自動。敵が `range` 以内に来ると振って、前方の敵をまとめて薙ぎ払う（`trySwing`）。敵の魔法（`shots` の `friend:false`）は剣では消えない。ジャンプか移動でよける
- 穴はどれも、ジャンプしなくても通れる道（幅24以上）を残す（`HOLES`）。落ちると HP −20 で近くの安全な位置（`findSafe`）に戻る。岩・箱はジャンプでこえられる（上に乗れる）、木はこえられない
- 勇者の HP が 0 でゲームオーバー

## 仲間

- `ALLY_SPOTS` の位置に立っていて、触れると仲間になる（最大4人＝勇者＋3人）。勇者のまわりの `SLOTS` についてくる
- せんし: 剣で自動攻撃（2ダメージ）／まほうつかい: 近くの敵へ火の玉を撃つ／そうりょ: 4.5秒ごとに一番減っている仲間を回復
- 仲間も HP を持ち、0 になるといなくなる。穴の上は跳ねてわたる（落ちない）

## 敵とボス

- `ET`: slime（はねる）、bat（飛ぶ・穴に落ちない）、skel（HP3）、wiz（距離をとって魔法を撃つ）
- 右端から出てくる。進んだ距離（`G.camX`）ごとの群れと、時間ごとの1体。カメラが `END-W` に着くとカメラを止めてボス戦
- ボス「やみの まじん」HP46。火の玉3発（HP半分以下で5発）と突進をくり返す
