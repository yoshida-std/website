# すすめ！ゆうしゃ（`games/Susume-Yusha/`）

スーファミRPG風の絵で、勇者が右へ進む横スクロールアクション（プロトタイプ）。公開URL: `https://yoshida-std.github.io/website/games/Susume-Yusha/`
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/KEX8vTqyZ5X9F5ju5pqruJ`（変更のたびにこの URL を更新する。`index.html` と、`files` で `sprites.png`・`sprites.json`・`logo.png`・`manifest.json`・`icon-192.png`・`icon-512.png`・`apple-touch-icon.png`・`sound/bgm_field.mp3`・`sound/bgm_boss.mp3`・`sound/jingle_clear.mp3` を同じパスで載せる）

## 概要と操作

- スマホ横画面専用。縦向きのときは「よこむきに してね」を出して一時停止する（`#rotate`）
- タイトル画面（`#titleView`、`showTitle`/`hideTitle`）: 操作エリアをかくしてゲーム画面を全幅にし（`body.titleMode`、`layout()` で `pw=0`）、勇者が1人でフィールドを歩く絵（`drawIdle`。穴は描かず、勇者の通り道 `TZ` の障害物も描かない）を背景に、ロゴ（ユーザーが作った絵 `logo.png`。金の字・剣・ドラゴンの影。透明の背景、599x355）・巻物の帯・右下に縦に並んだ「▶はじめる」「あそびかた」。「はじめる」を押すと、ロゴとボタンが消えて勇者が猛ダッシュで画面の右へ走りぬけ（`startDash`、`TD`。0.18秒ためて加速、土けむり・風の線）、出きったらゲームを始める（約1.4秒）。あそびかたはボタンで窓（`#howto`、2列6項目、とじる・窓の外タップ・Esc でとじる）を出す。スクロールなしで収まる大きさ（1em＝ゲームの8ドット）
- 画面の左 1/3 が操作エリア（`#panel`: パーティ窓と円盤）、右 2/3 がゲーム画面（`#screen`）
- ゲーム画面は高さ 224 ドットの canvas をドットのまま拡大。幅 `W` は右 2/3 の比率で 256〜440 に変わる（`layout()`）。ベルトスクロール型で、地面に奥行き（`z`）がある
- 絵: キャラは `sprites.png` から読む（下の「キャラのグラフィックシート」）。背景（空・雲・山2層・森・草原）、木・岩・箱・スライムは起動時に `buildArt()` で手続き的に描いておく（`ART`, `SP`）。ほかのキャラは文字列のドット絵に `shade()` で陰をつけ、`scale2x()` でなめらかに2倍にする（キャラは32ドット前後）。ボスのドラゴンはユーザーの絵（シートの `boss.dragon.*`）。コードの絵（`makeDragon()`、2コマ）はシートがないときの代わり。当たり判定・剣の間合いもこの大きさに合わせてある
- 操作エリアの絵: 石の板・光るひび・ルーンの輪・鷲（`drawPanel`）、盾の円盤（`drawShield`）、鋼のつまみ（`drawKnob`）を canvas に画面の解像度で描く。`layout()` のたびに描き直す。窓は青グラデーション（CSS）
- 強制スクロール: カメラは `SCROLL`（40px/秒）で右へ進む。左右を入れていないとき（上下だけのときも）、勇者はスクロールと同じ速さで前へ歩く（ボス戦では止まる）。勇者は画面の左端に押され、そのときは障害物もすり抜ける
- スタート時は勇者が左の画面外（x=-60）から猛ダッシュで入ってきて、x=70 で ずざっと止まる（`G.intro`、`G.introV`。止まる所に近づくほど遅くなる。約0.7秒。土けむり `fx.k='dust'`・風の線つき。その間は操作・スクロール・敵の出現なし）
- 移動の速さは左右 130、奥・手前 90（px/秒）。ジャンプの初速は 245（高さ約46ドット）
- 操作: 左の円盤（スティック）で上下左右（上下＝奥・手前）。中央のつまみを押して放すと、剣を振って三日月の斬撃を飛ばす（`castSlash`。基本12、0.35秒ごと）。長押しでため（`LV_T`: 0.5/1.0/1.6秒で1〜3段。ためられる段の上限は仲間の数 `maxLv()`。仲間がいないとためられない。仲間が加わるとメッセージで知らせる。段ごとに光の粒とつまみが 青→水色→金→赤 に変わり、音が鳴る）。放すと段に応じた大きな斬撃（`WAVE`: 基本 12/24/42/72）。1段以上の斬撃は敵をつらぬいて1体に1回ずつ当たり、敵の弾（魔法・ボスの火の玉）を消す。3段目は画面が揺れる。中央から始めたタッチは、そのまま指を動かせば、ためながら移動でき、放すと斬撃。矢印の上から始めたタッチは移動だけ。動かしながら別の指で円盤をタップしても斬撃。ジャンプボタンはない。円盤はタッチイベントで受け（`#panel` 全体。操作エリアの下側か円盤の円の中で始めたタッチ）、マウスはポインターイベント。PC は矢印/WASD、スペースで斬撃（長押しでため）
- パーティ窓（操作エリアの上、文字10px・HPバー5pxのコンパクトな窓）に HP と進み具合。一時停止ボタン（ひとやすみ）は画面の左上（操作エリアの一番上、パーティ窓の上）。ゲーム画面の右上は Claude アプリのボタンに隠れて押せないことがあるので置かない。ボタン（ひとやすみ・メニュー）は `onTap` で指を離したとき（touchend）にも動く（ホーム画面に追加した iOS アプリでは click が届かないことがあるため。click は二重にならないよう0.7秒は無視）。ひとやすみは押せる範囲を見た目より広くしてある（`::after`）。円盤は操作エリアの下側の空きに収まる大きさに合わせる（`fitStick`、ResizeObserver）。メッセージ窓はゲーム画面の上部（キャラが動けない空の部分）、ボスの HP はメッセージ窓の下の右側
- 自動ジャンプ: 進む先に穴か岩・箱があると、向こう側に届く速さで自動で跳ぶ（`autoJump`。跳んでいる間は踏み切ったときの速さ `hero.airV` で進む）。向こう側がない（木、地面の端まで続く穴）・着地点が画面の外になるときは跳ばずに手前で止まる
- 剣は自動。敵が `range` 以内に来ると振って、前方の敵をまとめて薙ぎ払う（`trySwing`）。敵の魔法（`shots` の `friend:false`）は剣では消えない。移動でよけるか、ためた斬撃で消す
- 穴はどれも、ジャンプしなくても通れる道（幅24以上）を残す（`HOLES`）。落ちると HP −20 で近くの安全な位置（`findSafe`）に戻る。岩・箱はジャンプでこえられる（上に乗れる）、木はこえられない
- 勇者の HP が 0 でゲームオーバー。勇者が白く光ってうしろへ倒れ（`drawMember` の `G.state==='over'`）、画面がだんだん暗い赤むらさきに沈む。1.8秒後にゲームオーバー画面（`showOver`）。クリア画面と同じ `#clearView` に `class="over"` で重ねる: 赤い字に銀のふちの「ゲームオーバー」（ゆっくり沈むように出る `cSink`）、銀の巻物の帯「ゆうしゃは ちからつきた…」、成績（すすんだ きょり・のこり・たおした てき・たすけた ひと）、金の「▶もういちど」と木目の「タイトルへ」
- 道の途中で町の人（`MOB`: まちびと・こども・むすめ・しょうにん・へいし・おひめさま・おうさま。`MOB_SPOTS`）も魔物に襲われている（仲間と同じ `updNpcs`、`n.mob`）。助けると `G.followers` に入り、画面の左の最後列をスクロールに合わせて歩く（`updFollowers`）。ボス戦の間は画面の外へかくれ、勝ったら入ってきて勇者たちの後ろに並び、喜んで跳ねる。クリア画面に「たすけた ひと」を出す
- 隠れキャラ「あいつ」（`MOB.aitsu`）: ユーザーの線画の白いキャラ（帽子・ねむそうな目）。町の人あつかいで、ゲームごとに `AITSU_RATE`（20%）の確率で `x:2010` に出て、魔物（スライム2・コウモリ）に襲われている。助けると「…なぜか ついてくる」。URL に `?aitsu` を付けると必ず出る。クリア画面の「たすけた ひと」の分母はそのゲームに出た町の人の数
- ボスをたおすと、勇者と仲間が順に小さく跳んで、正面を向いて剣や杖をかかげる決めポーズ（`CLS[].pose`。`POSE_HEAD`/`POSE_SWORD`/`POSE_STAFF`/`POSE_BODY` を重ねて作る）。勇者を真ん中に、画面の中央に横一列に並ぶ。約3秒後（町の人がいれば4秒後）にクリア画面。クリア画面（`showClear`、`#clearView`）はゲーム画面の上に重ねて、後ろの勝利の場面が見えるようにする（暗い窓は使わない）。青いグラデーションに金のふちの「ステージ クリア!」（Mochiy Pop One）、巻物の帯「ほのおの ドラゴンを たおした！」、大きな成績（タイム・たおした てき・のこった なかま・たすけた ひと、M PLUS Rounded 1c）、金の「▶もういちど」と木目の「タイトルへ」。順に出てくる動き（動きを減らす設定では止める）。大きさは 1em＝ゲームの8ドット（`layout()` で決める）

## ホーム画面のアイコン

- `manifest.json`（全画面・横向き）と、ユーザーが作ったアイコン（勇者の顔のドット絵）。Android は `icon-512.png`（もらった 512x512、透明の背景）と `icon-192.png`（512 を縮めたもの）、iOS は `apple-touch-icon.png`（もらった 180x180 を、透明の所が黒くならないようゲームの空の色のグラデーションに重ねたもの）
- `apple-mobile-web-app-capable` など、ホーム画面から開いたとき全画面になる meta を `<head>` に入れてある
- タイトルのコピーライトは丸ゴシックの太字（こげ茶のふち）で左下

## 音

- BGM は音声ファイル: `sound/bgm_field.mp3`（道中、BGM031「力を出しきれ」32秒）と `sound/bgm_boss.mp3`（ボス、BGM084「燃やしつくすぜ」41.14秒）。ユーザーがくれた WAV を ffmpeg で 128kbps の MP3 にしたもの
- WebAudio でくり返し流す（`BGM_FILES`, `bgmFile`）。MP3 の頭の無音を飛ばし、もとの WAV の長さでくり返す（`loopPoints`）。遊んでいる・音 ON・画面が見えているときだけ流し（`syncBgm` を 50ms ごと）、一時停止では止めて続きから。ボスをたおしたら止める（`stopBgm`）
- ステージクリアのジングル: `sound/jingle_clear.mp3`（ME044「clear12」7.3秒、1回だけ）。ボスをたおして勝利の場面に入ったときに鳴らす（`playJingle`）。タイトルへ・もういちどで止める（`stopBgm` が `stopJingle` も呼ぶ）。読めないときは合成のファンファーレ（`SFX.join`）
- 音量: 効果音は master 0.32、BGM のファイルは 0.24（`BGM_VOL`）、ジングルは 0.45（`JINGLE_VOL`）。BGM を抑えて効果音が聞こえるようにしてある。合成の BGM も小さめ
- 音声ファイルを読めないときは、前からある合成の BGM（`SONGS`）を鳴らす。効果音は合成（`SFX`）

## キャラのグラフィックシート

- `sprites.png`（ゲームが読むシート、透明の背景）と `sprites.json`（どの絵がシートのどこにあるか: `frames` の `名前: {x,y,w,h,s}`）。セルは「描くときの大きさ」で、ゲームは `s`（表示の倍率）に合わせて縮めて表示する（`shrink`: 面積の平均、ふちの半透明はなくす）。キャラ（勇者・仲間・町の人）は表示の 1.5 倍（48x48 → 32x32、s=2/3。ポーズ 48x60 → 32x40、こども 48x36 → 32x24）、敵・ドラゴンは表示の 2 倍（s=1/2。スライム 72x60 → 18x15（スライムだけ s=1/4 で小さめ）、ドラゴン 242x224 → 121x112）。表示の大きさ・当たり判定はこれまでと同じ。起動時に読みこみ（`loadSheet`）、コードで描いた絵の代わりに使う。読めないとき・URL に `?nosheet` を付けたときはコードの絵のまま（`SHEET.loaded`）
- 名前: `char.{hero|warrior|mage|priest}.{0|1|pose}`（0・1 は歩きの2コマ）、`mob.{town|child|woman|merchant|soldier|princess|king|aitsu}.{0|1}`、`enemy.{slime|bat|skel}.{0|1}`、`enemy.wiz.0`、`boss.dragon.{stance|roar|claw|flap}`（かまえ・ほえる・つめ・はばたき）
- 絵は右向き（左向きと、当たったときの白い絵はゲームが作る）。足もとがセルの下の端、左右の真ん中がキャラの立つ位置。剣・杖・槍・影はゲームが描く（決めポーズの剣・杖は絵に入っている）。絵に武器が入っているキャラは `sprites.json` の `weaponInSprite` に書くと、ゲームは武器（剣・杖・槍）を重ねて描かず、振ったときの軌跡だけ描く。いまは勇者・せんし（おの）・まほうつかい（杖）・そうりょ（杖）・へいし（槍）・おうさま（しゃく）
- 勇者はユーザーが用意した絵（64x64 を 48x48 のセルに縮めて入れたもの。表示は仲間と同じ 32x32。剣入り、決めポーズは親指を立てた正面向き）。`sprites.json` の `custom` に入れてあり、書き出しスクリプトで上書きされない。仲間・町の人・敵も勇者に合わせた絵に描きなおした（`tools/art/`。4倍の大きさで形・陰・こげ茶のふちを描き、勇者と同じ縮め方で縮める）。どれも `custom` に入れてある。あいつはユーザーの線画（`tools/art/src/aitsu_*.png`、左向き）を `tools/art/aitsu.py` で 32x32 の白黒ドット（s=1。目は描きなおし）にしたもの（作り直すときは `python3 games/Susume-Yusha/tools/art/aitsu.py` → `--from-sheet`）。描きなおすときは `tools/art/people.py`（`SPECS` に服・髪・かぶりもの・持ち物）と `tools/art/enemies.py` を直して `python3 games/Susume-Yusha/tools/art/gen_all.py` → `node games/Susume-Yusha/tools/export-sprites.js --from-sheet`（シートの最後に足してから並べなおす）
- 描きかえるときはセルの中だけを描く。セルの大きさを変えたら `sprites.json` の w,h も直す（当たり判定は変わらない）
- `sprites-guide.png` は名前と枠を書きこんだ見本（ゲームは読まない）
- `tools/export-sprites.js`: `node games/Susume-Yusha/tools/export-sprites.js` でコードの絵から描く大きさのシート・json・見本を作り直す（`custom` のコマはいまのシートの絵を使う。それ以外は描きかえていても上書き）。`--from-sheet` を付けると、いまのシートの絵をすべてそのまま使って並べなおし、見本も作り直す。`custom`・`weaponInSprite` は引きつぐ
- 木・岩・箱・背景はシートに入れていない（コードで描く）
- 専用エディタ（描く大きさのセルを編集。プレビューと表示の大きさはゲームと同じに縮めて見せる）: `tools/ys_spriteSheetEditer/`（公開URL `https://yoshida-std.github.io/website/tools/ys_spriteSheetEditer/`、確認用 Artifact `https://claude.ai/artifact/PLtp88E6JkvpB8jQ1p323j`。Artifact では書き出し・GitHub 保存・ゲームでためすは動かないので、本番は Pages で使う）。ゲームのシートを読み、コマを選んで画像の入れかえ（ドロップ・貼りつけ・ファイル。足もと下・左右中央に合わせ、大きければ縮める）とドットの描きなおし（ペン・消しゴム・スポイト・塗りつぶし・左右反転・元に戻す）ができる。プレビューで歩きの2コマを右向き・左向きで動かす
  - 「ゲームで ためす」: 描きかけのシートを localStorage（`susumeYusha.sheetPreview`）に入れ、ゲームを `?preview` で開く。ゲームはそのシートで動く（同じサイトの中だけ。保存はされない）
  - 保存: sprites.png の書き出し、または GitHub の Contents API で直接コミット（リポジトリ・ブランチ・場所・トークンを入れる。トークンは覚えさせたときだけ localStorage の `susumeYusha.ghToken`）。セルの大きさは変えないので sprites.json はそのまま

## 仲間

- `ALLY_SPOTS` の位置にいて、画面に入る前に魔物の群れ（`GUARDS`）に取りかこまれる（`updNpcs`。`state`: wait → captive → joined / lost）。群れを全部たおすと助けられて仲間になる（最大4人＝勇者＋3人）。助ける前に画面の左へ流れると `lost`（助けられない）
- 見張りの魔物は勇者が 96 以内に来るまで仲間のまわりを回って襲いかかる動き（`e.guard`, `e.aggro`）。とらわれた仲間はおびえて震える
- 仲間になると勇者のまわりの `SLOTS` についてくる
- せんし: 剣で自動攻撃（基本17）／まほうつかい: 近くの敵へ火の玉を撃つ／そうりょ: 4.5秒ごとに一番減っている仲間を回復
- 仲間も HP を持ち、0 になるといなくなる。穴の上は跳ねてわたる（落ちない）

## ダメージと命中演出

- HP と攻撃力は10倍の数値（スライム15・コウモリ14・ガイコツ30・まどうし20・ボス460。勇者の剣11・斬撃12・ためた斬撃24/42/72・せんし17・そうりょ6・火の玉8）。ダメージは基本値の ±15%、8% で会心（2倍）（`roll`）
- 当たると数字がとび出す（白、会心は黄色の大きな数字）。火花・斬撃の線・敵の震えを出し、剣のときは一瞬止める（`hitFx`, `G.hitstop`）。たおした敵はくるくる回りながら画面の外へ吹き飛び、出た所でキラッと光る（`launch`, `G.flyers`, `twinkle`）

## 敵とボス

- `ET`: slime（はねる）、bat（飛ぶ・穴に落ちない）、skel（HP3）、wiz（距離をとって魔法を撃つ）
- 体に触れたときのダメージに加えて、離れた所からの攻撃がある（`e.atk`: wind → leap / cut、`e.acd` が次の攻撃までの待ち）。まえぶれ（`wind`）の間は白く点滅して頭の上に「！」。はじめてのときメッセージで知らせる（`warnAtk`）
  - スライム: 横 26〜62・奥行き14以内で 0.5秒ちぢんでためて、ためはじめに勇者がいた所へ跳びかかる（0.38秒、速さ175）。上下に動けばよけられる
  - ガイコツ: 横36・奥行き13以内で止まって 0.6秒ふりかぶり、前 38 まで斬る（`skelCut`、弧の `eslash`）。上下に動けばよけられる
  - 仲間をねらう敵: 画面に入ったとき、仲間がいれば `ALLY_AIM`（35%）の確率で仲間の一人を `e.target` にする（まどうしは魔法を撃つたびに選びなおす）。間に勇者がいると上下に回りこむ（`dodge`）。ねらった仲間がいなくなったら勇者をねらう。はじめてのとき「まものが なかまを ねらっている！ まもれ！」
  - 敵の攻撃力（`ET` の dmg）: スライム9・コウモリ8・ガイコツ15・まどうし6（体当たり）、まどうしの魔法18、ボスの火の玉20・体当たり18（突進27）
  - ふりかぶり・跳びかかりの間は剣で押し返されない（`e.kx=0`）。スライム・コウモリは HP を上げて、剣（11）一発では倒れないようにした
- 右端から出てくる。進んだ距離（`G.camX`）ごとの群れと、時間ごとの1体。カメラが `END-W` に着くとカメラを止めてボス戦
