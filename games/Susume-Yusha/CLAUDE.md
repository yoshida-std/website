# すすめ！ゆうしゃ（`games/Susume-Yusha/`）

ファミコンRPG風の勇者が右へ進む横スクロールアクション（プロトタイプ）。公開URL: `https://yoshida-std.github.io/website/games/Susume-Yusha/`
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/KEX8vTqyZ5X9F5ju5pqruJ`（変更のたびにこの URL を更新する。`index.html` 1枚だけ。音は WebAudio で鳴らすので音声ファイルはない）

## 概要と操作

- 画面は 256×192 の canvas をドットのまま拡大。ベルトスクロール型で、地面に奥行き（`z`）がある
- 操作: 左下の円盤（スティック）で上下左右（上下＝奥・手前）、真ん中のボタンでジャンプ。PC は矢印/WASD とスペース
- 横向きのときは操作部品をゲーム画面に重ねる（`body.land`）
- 剣は自動。敵が `range` 以内に来ると振って、前方の敵をまとめて薙ぎ払う（`trySwing`）。敵の魔法（`shots` の `friend:false`）は剣では消えない。ジャンプか移動でよける
- 穴に落ちると HP −20 で直前の安全な位置（`hero.safe`）に戻る。岩・箱はジャンプでこえられる（上に乗れる）、木はこえられない
- 勇者の HP が 0 でゲームオーバー

## 仲間

- `ALLY_SPOTS` の位置に立っていて、触れると仲間になる（最大4人＝勇者＋3人）。勇者のまわりの `SLOTS` についてくる
- せんし: 剣で自動攻撃（2ダメージ）／まほうつかい: 近くの敵へ火の玉を撃つ／そうりょ: 4.5秒ごとに一番減っている仲間を回復
- 仲間も HP を持ち、0 になるといなくなる。穴の上は跳ねてわたる（落ちない）

## 敵とボス

- `ET`: slime（はねる）、bat（飛ぶ・穴に落ちない）、skel（HP3）、wiz（距離をとって魔法を撃つ）
- 右端から出てくる。進んだ距離（`G.camX`）ごとの群れと、時間ごとの1体。カメラが `END-W` に着くとカメラを止めてボス戦
- ボス「やみの まじん」HP46。火の玉3発（HP半分以下で5発）と突進をくり返す
