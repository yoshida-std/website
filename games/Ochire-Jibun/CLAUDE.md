# おちれ！自分の絵（`games/Ochire-Jibun/`）

スマホ縦画面向け。自分で描いた絵のキャラが穴をおちていく。公開URL（まだポートフォリオには載せていない）: `https://yoshida-std.github.io/website/games/Ochire-Jibun/`
リポジトリ全体の作業ルールはルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/4qF847JqRMxTc7c5ihN2cV`（変更のたびにこの URL を更新する。`index.html` 1枚だけ。Artifact 側が外枠を付けるので、載せるときは `<!doctype>` `<html>` `<head>` `<body>` と viewport の meta を外したコピーを使う）

## 流れ
1. タイトル → 2. お絵かき（24×24ドット、制限20秒、「OK」で短縮。ペン／けす／ぬる／もどす／クリア、16色）→ 3. READY→GO → 4. 30秒のおちるゲーム → 5. 結果（おなじ絵でもう1回／絵をかきなおす／タイトルへ）
- 前回の絵が次回のお絵かきの初期状態（`localStorage` の `ochire_art`。24×24=576文字、`.`=透明、`0`〜`f`=パレット番号-1）。初回・空のままOKなら初期キャラ（`defaultArt`）
- ベスト `ochire_best`（m）
- ランキングTOP5: `localStorage` の `ochire_rank`（`[{a:絵の文字列, m:記録m}]`、記録の大きい順、同じ記録は先に出したほうが上）。**この端末のブラウザだけ**（サーバーなし）。ゲームが終わるたびに `addRank`（0mは載らない）。タイトルと結果画面の「ランキング」ボタンで一覧（順位・絵・記録。今回載った行は点滅）。結果画面に「ランキング N位！」
- お絵かき画面の右上「TOP5の絵」ボタンでポップアップが開き、TOP5の絵をえらぶとエディタに読み込める（いまの絵は「もどす」で戻せる。TOP5が空ならボタンは出ない）。タイマーは止まらない

## 絵の評価（`evaluate`）
お絵かき中、絵を描くたびに3つのパラメータ（各1〜10）を出して画面に見せる。OK／時間切れの時点の値がゲームに効く（空のときは初期キャラの値）。
- おちるはやさ = 絵の「重さ」。塗ったドットごとに 0.6〜1.4（暗い色ほど重い）を足し、`ceil(合計 / (576×0.5) × 10)`。基本速度に ×0.7〜1.4
- よこのうごき = 絵の横幅（塗ったドットの左端〜右端）。`round(10.5 − 幅×0.42)`。左右の移動速度 200〜360px/s
- しょうがいぶつ = 使った色の数（最大10）。障害物の間隔に ×1.3〜0.75（多いほど詰まる）
- 初期キャラは はやさ5・うごき5・しょうがいぶつ6。READY の表示にも出す。低い画面（高さ700px以下）は表示を詰めている

## ゲーム
- 画面は論理幅360px固定、高さは画面に合わせる（`resizeGame`）。キャラは画面上から27%の位置に固定、世界が上へスクロール。1m=40px
- 操作: 十字パッド（指をずらして斜めも可）。◀▶ 左右移動、▲ ブレーキ（速度×0.4）、▼ かそく（×1.9）。キーボード矢印／WASDも可
- 基本速度 230px/s（30秒かけて +25%）。障害物にあたると、無敵のあいだ（トゲ1.6秒／岩・石板1.3秒＋0.15秒の余裕）ずっとスクロールが約10%まで落ちる（最後の0.3秒でなめらかに戻る。`hurt`）。点滅するのでそのあいだは当たらない
- スター（`star`）: 障害物と障害物のあいだに 13% の確率で出る（コインの代わり）。点滅しながら脈打つ黄色い星。取ると **3秒間むてき**（`starT`。にじ色に光り、最後の1秒は点滅。HUD に「★ 残り秒」）。むてき中に障害物にあたると、その障害物がくるくる回りながら画面の外へふっとぶ（`launch`。「ドカーン！」）。あたってもコインは減らず、減速もしない。あたった直後の減速中にスターを取ると、減速も無敵もすぐ解除してスター状態にする
- 障害物: トゲつき木の板（`ledge`）、石の板（`slab`）、岩（`rock`、深くなると横にゆれる）。間隔 235→195px（深さ約175mで最小）
- コイン: 障害物と障害物のあいだに 60% の確率で 1〜3 枚（たて並び）。拾うと「おちるはやさ」のレベルが +1（`baseLv + coins`、倍率 `scaleFor(l)=0.7+(l−1)/9×0.7` をなめらかに追従）。障害物にあたると コイン −1（0枚ならなし）。**下限は絵から決まった値（`baseLv`）、上限なし**（10を超えてよい）。取得時は画面に大きく「はやさ+1」（17px、ふくらんで消える）、あたると「コイン−1」。HUD に「はやさ N(+コイン数)」「コイン N」、結果画面に COIN
- キャラの周りに自動で白いふちを付ける（暗い背景で黒い絵が見えなくなるのを防ぐ）
