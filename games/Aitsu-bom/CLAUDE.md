# あいつのボンバ！ — 作業メモ

スマホ縦画面向けのブラウザゲーム。ラリーX（広いスクロール迷路、レーダー、旗集め）とボンバーマン（爆弾、壊せる箱）の組み合わせ。
クレジット：©YoshidaStudio, ©PANICPUMPKIN（タイトル画面と一時停止メニューに表示）

## 再開のしかた
- 公開先（正本）：https://claude.ai/artifact/3kn7u23QXubSZ6dA2nZjrx
- 作業環境はセッションごとに消える。ローカルファイルがなければ、Artifact の `read` で上の URL を読み、保存されたファイルから作業する。更新は同じ URL に publish する（URL を変えない）。
- スマホ対策はスキル `mobile-web-game-touch` に従う。

## 操作
- スマホ：丸いスティックで移動。外周に触れるかなぞると、その方向へ曲がる。中央の BOMB で爆弾を置く。片手で操作できる。ゲーム画面のスワイプで方向転換、タップで爆弾も可。
- PC：矢印キー / WASD で移動、Space / Z / X で爆弾、P / Esc で一時停止。
- 自機はラリーX式に止まらず進み、角で入力した方向へ曲がる。
- 右上の ❚❚ で一時停止メニュー（つづける / BGM ON・OFF / タイトルにもどる）。

## 決めた仕様
**目的**：旗を全部取るとラウンドクリア。全10ステージ。最後まで行くと ALL CLEAR 画面。

**マップ**
- 外周と偶数座標は壊せない壁、ランダムに木箱（約32%）、巣、旗。
- サイズはステージ1が 13×17、ステージ10が 25×33（最大）。間の面は線形に広がる。
- 旗は10本で、1本は緑の S 旗（得点2倍）。マップが狭いと10本置けないことがある。

**自機（添付のキャラクター風。白い体、黒い帽子、半目）**
- 歩くアニメーション（足と腕を交互に動かし、上下に揺れる）。進行方向で左右反転。
- 自分や他の爆風に当たっても死なない。
- 爆風を浴びると2秒間「火まとい」。この間は敵に体当たりで倒せる。浴び直すと2秒にリセット。
- 爆弾と同じマスには重ならない。置くと隣の空きマスへずれる（前、横、後ろの順）。空きがなければ置けない。
- 死ぬのは敵に触れたときだけ（距離 0.7 マス未満）。ライフ3。0 からさらにやられるとゲームオーバー。

**おなか（旧・燃料）**
- 毎秒 1.25 減る。旗で +8、おにぎりで +35。
- 30 未満で「おなかペコペコ…」、速度が最低 40% まで落ちる。0 でも死なない。
- ラウンドクリア時、残りのおなか ×10 点がボーナス。

**爆弾**
- 導火線 2.2 秒。爆風は 0.6 秒残る。初期は2個・射程2、どちらもアイテムで最大6まで。
- 爆風は壁で止まる。木箱と巣は壊れて、そこで止まる。
- 誘爆：爆風の中の爆弾はすぐ爆発する。爆風の中に置いた爆弾は即爆発し、個数制限に数えない（連打で爆風に乗って進める）。
- 旗が爆風で焼けると消え、その場からスライムが1体出る。

**アイテム（木箱から）**：爆弾の絵（個数+1）10%、炎（射程+1）10%、おにぎり 10%、ドル袋 6%。出てから0.6秒たつと爆風で消える。

**敵**
- 黄色いスライム：目玉つきで、ぴょんぴょん跳ねる。迷路に沿って追跡し、追跡率はラウンドごとに上がる。
- ゴースト：ラウンド3から。壁をすり抜けて自機へ寄ってくる。壁の中にいる間は爆風が届かない。
- 敵は巣からだけ出る。倒した敵は復活しない。
- 巣：ステージ1は1個。2面ごとに+1、最大6個。開始時に巣1個あたり2体を出し、その後は一定間隔で1体ずつ出す（間隔はステージが進むほど短く、最短3.5秒）。爆風1発で壊れる。
- 同時に出られる数：スライムは 4+ラウンド（最大10）、ゴーストは最大4。
- やられて再開すると、生きている敵は巣の位置に戻る。

**スコア**
| 内容 | 点 |
|---|---|
| 旗 | 100 × その面で取った数（S 旗は2倍） |
| 爆風で敵 | 100 × 2^同時撃破数 |
| 火まとい体当たり | 200 × 連続数 |
| 巣 | 1000 |
| ドル袋 | 2000 |
| 木箱 | 10 |
| アイテム | 50 |

ハイスコアは localStorage（`bombrally-hi`）。BGM の ON/OFF も保存（`bombrally-mute`）。

**画面**
- 外枠はパステル（ラベンダー / ピンク / ミント）。プレイ画面とレーダーは暗い紺紫。
- フォントは M PLUS Rounded 1c（本文）と Mochiy Pop One（見出し）。
- HUD は SCORE（左半分、数字は右詰め、右上に HI）、ROUND n/10、LIFE ♥n、一時停止ボタン。その下におなかゲージ、巣の数、旗の数。
- タイトルは「あいつの／ボンバ！」の2行。後ろにキャラクターの透かし、コピーライトはタイトルの上。
- 音：BGM はループ再生（スタートで開始）。ゲームオーバー時にジングルを鳴らし、BGM を止める。効果音は WebAudio で合成。

## ファイル構成
- `bomb-rally.html`：ゲームのすべて（1ファイル）。CSS、JS、素材をすべて含み、約1.6MB。
  - 素材は base64 で埋め込み：`window.BGM_B64`（BGM、MP3 112kbps）、`window.OVER_B64`（ゲームオーバー音）、`#mark`（透かし PNG）。
  - JS の主な区分：audio / state（newRound, resetPositions, nest）/ helpers（move, enemyDecide, ghostDecide, placeBomb, explode）/ update / render（drawHero, drawSlime, drawGhost, drawNest, drawItem, drawAura）/ input / overlay（showOverlay, pauseGame, toTitle）。
- 元素材（ユーザーの添付。セッションが変わると残らない）
  - BGM：`BGM153-131031-maigonomori-wav-nointro.wav`（約84秒）
  - ゲームオーバー音：`ME025-110124-clear05-wav.wav`
  - キャラクター線画 PNG（自機のデザインと透かしに使用）
- 素材を差し替えるときは ffmpeg で MP3 にして base64 で入れ直す。

## 未完成・既知のバグ
- コントロール部分のダブルタップ拡大対策（touchstart で preventDefault する方式）は、実機で未確認。
- BGM のループのつなぎ目に、すき間が出るかどうか未確認。
- 小さいマップでは旗が10本置けないことがある。旗の数は可変のまま動く。
- ゴーストが壁の中にいると爆風で倒せない（仕様として放置中。不評なら直す）。
- `drawCar` 関数が未使用のまま残っている。
- 自機キャラクターの再現度はユーザーの確認待ち（帽子の形、目の大きさなど）。

## やらないと決めたこと
- 自機は爆風で死なない（最初は死んでいたが撤回）。
- おなかが空になっても死なない（旧「ガス欠でアウト」は撤回）。
- 敵の車は使わない（スライムとゴーストに置き換え）。
- 十字ボタンは使わない（丸いスティック＋中央 BOMB に置き換え）。
- 敵の無限リスポーンはしない（巣からだけ出る）。
- 自機と爆弾は重ならない。
- BGM ボタンは HUD に置かない（一時停止メニューの中）。
