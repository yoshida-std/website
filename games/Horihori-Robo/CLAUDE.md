# ホリホリ・ロボバスター（`games/Horihori-Robo/`）

スマホ縦画面向けの縦スクロール穴ほりアクション（仮題。名前・フォルダ名は変えてよい）。公開URL: `https://yoshida-std.github.io/website/games/Horihori-Robo/`
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/1JWDnmdpVxVJC3r7oNmZKN`（変更のたびにこの URL を更新する。`index.html` と、`files` で `robo.png` `bgm.mp3` `dig.wav` を同じパスに載せる。`Artifact` ツールが使えないときは `publish_files`（`mcp__claude-artifacts`）で、リポジトリのファイルをそのまま公開する）

`index.html` と、キャラのスプライトシート `robo.png`（1024×768、128px のコマ 8×6）と、BGM `bgm.mp3`、穴を掘る音 `dig.wav` で完結（ほかの効果音は WebAudio の合成）。`games.json`（ポートフォリオの一覧）にはまだ載せていない。

## 概要と操作

- ファミコンのボンバーマン風の迷路（幅13マス）。**画面は強制的に上へスクロール**し、下に押しつぶされる前に、一番上の **出口（1つだけ。「GOAL」の青白チェッカー）** へ着けばステージクリア。出口の前の1行（行2）は壁で、出口の真下の1マスだけが通れる。**行1〜2の壁にはハシゴをかけられない**（`ty>=3`）。無限にステージが続く
- 左下のスティックで4方向に移動、右下の「ホル」ボタン（**スティックの円盤・ポーズボタン以外の画面のどこをタップしても同じ**。片手で遊べるように。`digIds` で押している指を数える）で穴をほる（ロードランナー式）。**自動ねらい**: 歩いて5マス以内（`AIM_RANGE`。プレイヤーを起点にした BFS の距離 `flow` で測る）に、画面内で動いているロボがいれば、そのロボの来る道すじの最後の1マス（プレイヤーのとなり）にほる（ロボが真横にいればそのマス）。いなければ **向いている方の1マス先**。ねらった方向をむく。ハシゴは「向いている方向が壁のとき」だけ（ロボが近いときはロボを優先）。**埋める連続**: 穴を埋めたあと2秒以内（`lastFillAt`）は、タップのたびに、プレイヤーのとなりに開いたまま残っている別の穴（ねらいの方向を先、なければ上下左右の順）を埋める。となりに穴がなくなったら、ふつうのねらいにもどる（新しく掘る）。0.5秒以上の長押しで連続（ふつうのタップが少し長くなっても2回ほらない）。走りながらでも、次のマスの境目でほる（ボタン入力は0.4秒ためておく）。向いた先に穴があれば、もう一度「タップ」すると埋める（押しっぱなしでは埋めない。押しっぱなしは新しい穴を連続でほるだけ）（トラップ中のロボごとつぶす +300）。ロボが立っているマスにもほれる（その場で穴に落ちる）。キーボード: 矢印/WASD、Space/Z/X、P でポーズ
- 穴は約5.5秒でふさがる（終わり際に点滅して縮む）。白いロボは穴に落ちて「トラップ」状態（約3〜4秒で這い出る）。**トラップ中のロボの頭は踏んで渡れる**（初回 +200）。穴がふさがるとロボはつぶれる（+300）
- **ハシゴ**: 壁（外周とゴール行より上は除く）に向かってホルボタンを「タップ」すると、その壁のマスにハシゴがかかり、通れるようになる（ロボも通る。グリッド値 2）。1ステージに3つ（HUD の「ハシゴ」）。押しっぱなしでは置かない。ハシゴのマスには穴はほれない
- **金塊の山**: 1ステージに10か所（`GOLD_N`）。迷路の高さを10に分けた帯ごとに1つずつ、ランダムな床に置く（`placeGold`）。触れると +300（`GOLD_PTS`）。ステージ内で10個ぜんぶ取ってゴールすると「PERFECT!」ボーナス +3000（`PERFECT_PTS`）。画面の下に流れたものは取れない。HUD の「金」に取った数
- **赤いロボ**: 強制スクロールが止まった（`camY<=0`）あと、画面の下から1体だけ登場する（1ステージ1回。`spawnRedRobot`、画面中央にバナー「あかいロボが きた！」）。赤い体、速さ 3.1マス/秒（ふつうのロボは最大2.6）、待機の列には入らず、やっつけると +1000（穴でつぶす 300＋700）。ふつうのロボは、スクロール停止後は新しく出てこない
- プレイヤーも穴に落ちる（約1秒で這い出る。その間にふさがる・ロボにさわられるとミス）
- ミスの条件: ロボにさわる／**強制スクロールで壁に挟まれる**／穴に埋まる。画面の下辺に触れただけではミスにならず、下辺がプレイヤーを上へ押し上げる（空いているマスなら1マス上へ自動で歩かされる）。押し上げる先（真上のマス）が壁だと「かべに はさまれた！」でミス。穴にはまって動けないとき（`stuck`）に下辺が来てもミス。`squeezeLimit()` が下辺の限界（`camY+viewRows-0.7`）で、プレイヤーは下向きにこれより下へは入れない。**ミスは3回まで**（3回目でゲームオーバー）。ミス後は画面中ほどの近くで復活し、2.5秒の無敵。復活したあと、強制スクロールが2秒（`RESPAWN_PAUSE`）止まってから再開する
- スコア: ロボ踏み 200、つぶす 300、金塊 300、前進 1マス 10、クリア 1000＋残りライフ×500、パーフェクト 3000。ベストは `localStorage` の `horihori_best`

## 実装メモ

- 迷路: セル 6×R（R = min(16+3n, 32)）を growing tree（新しい方/ランダムを半々）で掘り、15% の壁を抜き、3×3 の部屋（中央に柱）を足す。全体を2行下げて、上に出口の行（行1）と壁の行（行2）をつけ、奇数列のどこか1つ（`exitX`）だけ縦に抜く。最下段は柱つきのスタート部屋。偶数×偶数の柱は壁のまま
- 生成後に最短経路を調べ、「プレイヤー速度 2.8マス/秒、2.2秒の猶予」でスクロールに追いつけるか確認して、だめなら作り直す（40回まで）
- スクロール速度 `min(2.0, 0.95+0.12n)` マス/秒。プレイヤーが上から 40% より上にいるときは 2.4 倍で追いかける
- ロボ: 全部で `MAX_ROBOTS`=5 体（画面にいるのは最大5体）。迷路には置かない。ステージ開始時は5体とも画面の上の「ロボ待機」の帯に一列に並び、2秒後から1.4秒ずつずらして出てくる。やられたロボ（つぶされた・画面の下に落ちた・復活のときに近くにいて消された）は帯の最後尾に並び、`respawnDelay()`＝`max(4, 7.5-0.4n)` 秒たつと、先頭のロボが帯の上をすべって迷路の上端の空いたマスに降りてくる。残りは1つずつ前に詰める（`updQueue`）。各ロボの下の緑の棒が復活までの進み具合で、あと0.9秒で目が点滅して跳ねる。スクロールが上端に着いてゴールが近い（`camY<3`）間は出てこない。プレイヤーを起点にした BFS の距離を下るので穴を避けない。ほかのロボが歩いているマスには入らず行列になる。速度 `min(2.6, 1.6+0.15n)`（プレイヤーの 3.9 よりだいぶ遅い）
- 移動はマス単位のなめらかな歩み（`advance`）。歩きの途中で逆向きには即座に戻れる
- スティックの外側に、一回り大きい点線の円（`#stick::after`、「この外側タップで ホル」）を出して、ホルのタップ領域を見せている（実際は円盤以外のどこでも反応する）
- 見た目は「斜め上から」の2.5D（ボンバーマン風の明るい配色: 砂色・黄緑の床、オレンジのレンガ壁、青いHUD）。床を全部描いたあと、行ごとに壁（上面を `WALL_H`=0.3マス分持ち上げて前面を描く）→その行のロボ・プレイヤーの順に描いて隠れ方を作る。キャラは `y+0.38` を中心に描く（マスより少し上）
- **キャラクターはスプライトシート `robo.png`**（ユーザー提供の白いロボットのシートから、背景を透明にして128px に縮めたもの。元は 2400×1792 の JPEG で、300px のコマ）。コマ: 行0＝正面の立ち（0〜3）・背面（4〜7、5 は しっぽを振る）／行1＝右向きの歩き8コマ／行2＝左向きの歩き8コマ／行3＝ハシゴをのぼる8コマ／行4＝ショベルで掘る（0 は構え、1〜7 が掘る）／行5＝やられ（0〜2 は目がバツ）、3 は頭が熱くなる、4・5 は万歳、6・7 は目をとじる。
  - 3色: 白（ふつうのロボ）、**主人公＝黄色いロボ**、赤いロボ。起動時に白いシートからピクセルを塗り替えて作る（`recolor`: 白・灰色の体に色をかけ、青い部分（耳・胸のパネル）を暖色に）。主人公は黄色に橙の耳、赤いロボは赤
  - 向き: 左右は行1・2、上は背面、下は正面。上下の歩きは専用のコマがないので、立ちのコマを速く切り替えて上下にはねさせる。ハシゴのマスにいるとき（ロボもプレイヤーも）は行3
  - 主人公: 掘るときは行4（`digDur` の進みでコマを送る。左向きは左右反転）、穴にはまっているときは頭だけ（正面）、ミスのときは行5（頭が熱くなる→バツ目）。ロボ: 穴に落ちると行5 の目がバツ。待機の列で出番が近い（あと0.9秒）と、頭が熱くなるコマと立ちを交互に
  - タイトルに4体（主人公・ロボ・バツ目のロボ・赤いロボ）、クリアに万歳の主人公、ゲームオーバーにバツ目の主人公を CSS（`.spr`、`--hero-sheet` `--boss-sheet`）で出す
  - 画像が読めなかったときは、従来の矩形描画（`drawRobotVec` `drawPlayerVec`）で出る
- **BGM** `bgm.mp3`（ユーザー提供。PANICPUMPKIN の曲「ちんけなくらし」、約2分25秒、2.9MB。コピーライト表記の PANICPUMPKIN はこの曲）。音量は小さめ（`BGM_VOL`=0.2。効果音より控えめ）。`fetch` → `decodeAudioData` → `AudioBufferSource` のループ（iOS でも音量が効くように WebAudio）。末尾の約1.5秒の無音はループに含めない（`BGM_LEN`=143.7）。ゲーム中だけ鳴る: スタート（`newGame`）で頭から、ポーズ・画面を離れる・ステージクリアで一時停止（位置を覚えて続きから）、つぎのステージ・つづけるで再開、ゲームオーバー・タイトルへで止める（頭に戻す）。ポーズ画面の「おと」OFF では鳴らさない
- **穴を掘る音** `dig.wav`（ユーザー提供、0.08秒、13KB）。穴をほるとき・埋めるときに鳴る（`SFX.dig` → `playDigSound`、音量 0.55）。読み込み前や失敗時は、合成の短い音で代用
- 穴の見た目はすべて canvas の矩形描画（デバイスピクセル単位で `S`＝1マスのpx）
- プレイヤーの歩く速さは `PSPD`=3.9マス/秒。ミス・ステージ開始のとき、ホルボタンの入力（`digReq` `digFresh` `digHeld`）を捨てる。`play` 以外の状態で押したホルボタンは無視する（死んだ直後のタップで復活後に掘れてしまう不具合の対策）
- デバッグ用に `window.__dbg`（状態の参照）がある。消してよい

## 確認のしかた

`python3 -m http.server` で配信し、Playwright（iPhone 13 / SE）で開く。`__dbg` から `pl`・`ens`・`holes` を直接書き換えると、穴に落とす・踏む・ふさがる、などの場面を作れる。
