# ホリホリ・ロボバスター ファミコン版

ブラウザ版(`../index.html`)をファミコン実機(NROM / マッパー0)向けに移植する作業フォルダ。

## ビルド
cc65(ca65/ld65)と Python3(Pillow)が必要。`make` で `build/horihori.nes` ができる(EverDrive N8 のSDカードへ)。
`assets/` は `tools/make_assets.py` が `../robo.png` から作る(CHR・背景・衝突マップ)。

## 確認(ヘッドレス)
`node tools/run_headless.mjs build/horihori.nes 出力prefix "right:40,down:30"`(jsnes が必要)で画面を書き出せる。

## 進捗
- 第1段階: 16x16キャラ表示、十字キー歩行、白/黄/赤のパレット違い
- 第2段階: 壁の当たり判定(衝突マップ 16x16)
- 第3段階: ブラウザ版と同じマス単位の歩行(マスの途中で逆向きに戻れる。通路に入りやすい)
- 第4段階: 縦長の迷路(31行・仮の固定迷路)を強制スクロールで下から上へ。画面の上端に出る行だけ背景に書き込む(ネームテーブル上下2面の輪)
- 第5段階: 画面の下辺に触れたら1マス上へ押し上げ、上が壁ならミス(残機3、復活後2秒スクロール停止)。残機0でGAME OVER、Startで最初から
- 第6段階: タイトル画面(PUSH START)。Startを押すまでの時間を乱数の種にして、6502で迷路を自動生成(growing tree方式。RAM上に13x31)。ゲームオーバー後のStartでも新しい迷路
- 第7段階: 穴掘り。A/Bボタンで向いている先のマスに穴(約5.5秒でふさがる。終わり際に小さくなる)、もう一度押すとうめる。主人公は穴のマスの中心で落ちて1秒動けない。ふさがるとき中にいるとミス
- 第8段階: 白いロボ(2体)。待機→出現→主人公を追いかける(幅優先探索を1フレーム24マスずつ段階処理)。穴に落ちて約3.5秒で這い出る、頭を踏んで+200、ふさがってつぶれて+300(8秒後に再出現)、さわるとミス(無敵点滅とロボ退場)。スコアは左の余白に縦5桁
- 第9段階: 迷路の一番上に出口(チェッカー)。着くとSTAGE CLEAR(ボーナス=1000点+残機x500点、残機+1)。全5ステージ(スクロール0.90〜1.40マス/秒、ロボの速さ1.70〜2.55、ロボ=ステージ番号の数、復活待ち8.0〜4.6秒)。5面クリアでALL CLEAR、Startで最初から
- 第10段階: 金塊(1ステージ10個、10の帯に1つずつ。取ると+300、全部取ってクリアでPERFECT +3000)。1マス上へ進むごとに+10。取った数をHUDに表示。背景は上下別タイル(2x2)に対応
- 第11段階: ハシゴ(1ステージ3本。壁に向かって止まってから1.5秒以内にA/B)、ストップウォッチ(取るとスクロールが10秒止まる。残り秒を表示)、赤いロボ(スクロールが止まったら下から登場。つぶすと+1000。白いロボはそれ以降出ない)
- 第12段階: 音。BGM(オリジナルの8小節ループ。矩形波+三角波)と効果音11種(矩形波2+ノイズ)。ボタンは A=掘る/うめる(自動ねらいなし)、B=ハシゴ
- 第13段階: スコアなどの表示を画面の上部(黒地の32px)に移動。スプライト0でスクロールを切り替える。迷路の窓は208px(13マス)
- 第14段階: BGMをブラウザ版の曲の自動採譜(メロディ+ベース)に差し替え。タイトル画面に©表記(YoshidaStudio・PANICPUMPKIN)
- 第15段階: ステージの間に黒いクリア画面(ボーナス・金塊・PERFECT・残機回復・スコア、点滅するPUSH START。ALL CLEARはランク)。ステージ開始時にゲーム画面の上へ「STAGE x」を3秒。ゲーム画面の文字は黒い四角つき
- 第16段階: ポーズ(Start。RESUME / RETIRE / TITLE を上下+Aで選ぶ)
- 第17段階: タイトル画面(黒地・壁ブロックの枠のタイトル・3体のロボ・上から降りてくるスクロール・©2026)、ハイスコアの記録と表示(電池つきRAM)
- 第18段階: クリア画面の演出(ステージクリア=黄色いロボが左から右へ歩く、ALL CLEAR=真ん中で飛び跳ねる)
- 第19段階: スクロールはゲーム開始から5秒後に始まる
- 第20段階: 白いロボは出る約1.7秒前に、画面の左右の余白(交互)を下から上へ走り上がり、画面上部に着いたら迷路の上端に登場する
- 第21段階: 白いロボは画面の一番上の行の壁でないマスから出る(他のロボと重ならない)
- 第22段階: ハシゴをゴールの次の行にもかけられる。1つの穴にはロボ1体まで
