# ちびうぱのエサキャッチ！（`games/Chibiupa-Tank/`）

スマホ横画面・スクロールなしの固定画面。水そうの中をちびうぱが泳ぎ、上から落ちてくる人工エサをキャッチする。公開URL（まだポートフォリオには載せていない）: `https://yoshida-std.github.io/website/games/Chibiupa-Tank/`
リポジトリ全体の作業ルールはルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/VCdowGubUF6gCxXRSAujKH`（変更のたびにこの URL を更新する。`index.html` と `img/chibiupa.png` を同じパスで載せる）

## ファイル
- `index.html` … 1枚完結（canvas 描画。音は WebAudio の合成音でファイルなし）
- `img/chibiupa.png` … ちびうぱ（ユーザー提供GIFの1コマ目を切り出した透過PNG、174×152）。ゲームでは**頭と顔だけ**をこの絵から使い（`drawPlayer`。y<94 で切り出す）、体（どう体・足・うで・しっぽ）は canvas で描き足している（`drawBody`）

## 仕様
- 世界は高さ400固定、幅は水槽の枠（`#stage`）の比（1.1〜2.4）に合わせて 440〜960。左右にボタン用の余白（`--rl` `--rr`）を取り、水槽は中央に寄せてボタンと重ならない。砂の上 `FLOOR=H-38`。水槽（`tankFor(stage)` の `{L,R,WT}`）はステージごとに大きさがちがい、`TL` `TR` `WATER` がいまの水槽の左右・水面。**ステージ5の水槽＝全幅**（高さは全ステージ同じ）。上の空きにHUDとふりかけ容器が入る
- **全5ステージ**（`stage`）。クリア条件は `GOALS=[12,16,20,25,30]` 個（エサ1・ヌマエビ3 で数える `stageEaten`。HUDの「あと」）。水槽の幅は `TW=[.62,.72,.82,.91,1]`、水の深さは全ステージ `TH=.89`（深さの基準は H−96=304。ステージ4の高さに固定、水面は y≈129）で、**幅だけ**ステージ1→5へだんだん大きくなる。**新しい水槽に入るたびに、にごり（`lost`）・おなか・エサ・うんち・ヌマエビ・スポイトはリセット**（きれいな水）。得点 `eaten` は通しで数える（ベスト対象）。ステージ5をクリアすると「ぜんぶ クリア！」（`gameOver(true)`）
- ステージ1は、💩ボタンを隠し（`body[data-stage="1"]`）、ヌマエビ・スポイトは出ない（`stage>=2` から）
- ステージ移動の演出（`startTrans` → `updateTrans`、状態 `trans`）: `clear`（「ステージ クリア！」、エサは消える、1秒）→ `scoop`（網が上から下りてきて水面で水しぶき、1.1秒）→ `lift`（網でウパをすくって水面の上へ、1秒）→ `slide`（古い水槽が左へ、新しい水槽が右からスライド、網はウパごと新しい水槽の真ん中の上へ、1.7秒）→ `lower`（網をおろして水に入れる、水しぶき、0.9秒）→ `release`（`startStage` で新ステージ開始、ウパを放す、網は上へ引きあげる `net.rising`、「ステージ n」のバナー）。この間は操作できない・ポーズできない。描画は `drawTankBack`/`drawTankFront`（水槽ごと・横ずらし付き）と `drawNet`
- 操作（スーパーマリオの水中風）: 左下 ◀ ▶ で横移動（慣性あり、最大150px/s）、右下「およぐ」でひとかき（上向き速度 −165）。放っておくとゆっくり沈む（重力260、終端85）。長押しは 0.25 秒後から 0.3 秒ごとにひとかき。キーボード: ←→/AD、Space/↑/W、Esc でポーズ
- エサ: 上のふりかけ容器が動いて落とす → 空中 `air` → 水面 `float`（1.3〜2.3秒、レベルで短く）→ ふらふら沈む `sink`（速度 24〜34 + レベル×2.4、横ゆれ）→ 砂に着く `rest`（砂の中の深さは0〜6px。4.4秒、レベルで最短2.8秒。周りの輪で残り時間、最後の1.3秒は点滅）→ 消えたら「にげられ」
- 5つ消えるとゲームオーバー。1つ消えるごとに `dirtTarget = lost/5` で水が緑茶色に濁り、ゴミ粒が増える
- レベル = `(stage−1)×2 + floor((stageEaten + 消えた×2)/5)`（最大12）。上がるほど落とす間隔が短く（2.6→1.0秒）、レベル3以上で2個同時もある
- 演出: およぐ・横に進むと体が後ろに傾き、足をバタつかせてうでをかく（`P.swim` `P.ph`）。エサが80px以内に近づくと口をあーんと開け（`P.near`）、食べると0.55秒、にっこり目で口をもぐもぐ（`P.munch`。元の目と口の上を肌色でぬって描きかえる `drawFace`）
- 食べる判定: 空中以外は口（`P.y+4`）から半径27px。砂の上の `rest` は横±32px・縦±30px と広め（底のエサが取れない不具合の対策。ちびうぱが底に座ると `y=FLOOR-14`）
- おなか・うんち: エサを食べるたび `P.stomach++`（最大 `FULL=10`）。10でおなかいっぱい＝動きがにぶる（横の最高速 150→80、ひとかきの勢い 165→118で間隔1.4倍、沈むのが速い、体が少しふくらむ）。右の💩ボタン（またはキー P/S/↓）でうんち（おなか1以上で押せる。おなかが0になり、にぶいのも治る）。ボタンの輪がおなかの量、満タンで赤く点滅
- うんちはエサと同じように沈み、砂に着いて `POOP_REST=4` 秒たつと消えて **エサ2つ分のにごり**（`miss(q,2)`、5つ消失でゲームオーバー）。食べられない
- スポイト: 約5〜9秒おき（最初は9秒後）に左右どちらかの水面から入り、水深の45〜62%のところで8.5秒とまって戻る（同時に1本）。先の半径58px（点線の輪）に入ったうんちを引きよせ、13px以内で吸いとる（にごりなし、「きれい！」）。おなか5以上のときは輪の上に💩を出す
- ヌマエビ（生きエサ）: エサを2つ以上食べたあと、エサ出しのたびに20%で、エサの代わりにヌマエビを落とす（容器が「ヌマエビ！」と出す）。**場に出るのは最大4匹**（`MAX_SHRIMP`）（落下待ち・容器の中も数える）。落ちかたはエサと同じ（空中→水面→沈む）が、底に着くと `walk` になり**消えない**。底を歩き回り（22px/s）、砂の上の `rest` のエサ**とうんち**があれば一番近いものへ向かい（42px/s、他のエビが狙っているものは避ける）、近づくと食べる（0.7秒もぐもぐ。エサ・うんちは消えるが**にごりにならない**）。プレイヤーが食べると +3点・おなか+2（食べる判定はエサと同じ。砂の上は横±32px・縦±30px）。ゲームオーバーまで残る
- ベストは `localStorage` の `chibiupa_best`
- 縦向きだと「よこむきにしてね」を出して自動ポーズ。タッチ抑止はルート CLAUDE.md の方針どおり（`KEEP='button,.menu'`）
- デバッグ用に `window.__game` を公開している
