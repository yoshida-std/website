# ちびうぱのエサキャッチ！（`games/Chibiupa-Tank/`）

スマホ横画面・スクロールなしの固定画面。水そうの中をちびうぱが泳ぎ、上から落ちてくる人工エサをキャッチする。公開URL（まだポートフォリオには載せていない）: `https://yoshida-std.github.io/website/games/Chibiupa-Tank/`
リポジトリ全体の作業ルールはルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/VCdowGubUF6gCxXRSAujKH`（変更のたびにこの URL を更新する。`index.html` と `img/chibiupa.png` を同じパスで載せる）

## ファイル
- `index.html` … 1枚完結（canvas 描画。音は WebAudio の合成音でファイルなし）
- `img/chibiupa.png` … ちびうぱ（ユーザー提供GIFの1コマ目を切り出した透過PNG、174×152）。ゲームでは**頭と顔だけ**をこの絵から使い（`drawPlayer`。y<94 で切り出す）、体（どう体・足・うで・しっぽ）は canvas で描き足している（`drawBody`）

## 仕様
- 世界は高さ400固定、幅は水槽の枠（`#stage`）の比（1.1〜2.4）に合わせて 440〜960。左右にボタン用の余白（`--rl` `--rr`）を取り、水槽は中央に寄せてボタンと重ならない。水面 `WATER=62`、砂の上 `FLOOR=H-38`
- 操作（スーパーマリオの水中風）: 左下 ◀ ▶ で横移動（慣性あり、最大150px/s）、右下「およぐ」でひとかき（上向き速度 −165）。放っておくとゆっくり沈む（重力260、終端85）。長押しは 0.25 秒後から 0.3 秒ごとにひとかき。キーボード: ←→/AD、Space/↑/W、Esc でポーズ
- エサ: 上のふりかけ容器が動いて落とす → 空中 `air` → 水面 `float`（1.3〜2.3秒、レベルで短く）→ ふらふら沈む `sink`（速度 24〜34 + レベル×2.4、横ゆれ）→ 砂に着く `rest`（砂の中の深さは0〜6px。4.4秒、レベルで最短2.8秒。周りの輪で残り時間、最後の1.3秒は点滅）→ 消えたら「にげられ」
- 5つ消えるとゲームオーバー。1つ消えるごとに `dirtTarget = lost/5` で水が緑茶色に濁り、ゴミ粒が増える
- レベル = `floor((たべた + 消えた×2)/5)`（最大12）。上がるほど落とす間隔が短く（2.6→1.0秒）、レベル3以上で2個同時もある
- 演出: およぐ・横に進むと体が後ろに傾き、足をバタつかせてうでをかく（`P.swim` `P.ph`）。エサが80px以内に近づくと口をあーんと開け（`P.near`）、食べると0.55秒、にっこり目で口をもぐもぐ（`P.munch`。元の目と口の上を肌色でぬって描きかえる `drawFace`）
- 食べる判定: 空中以外は口（`P.y+4`）から半径27px。砂の上の `rest` は横±32px・縦±30px と広め（底のエサが取れない不具合の対策。ちびうぱが底に座ると `y=FLOOR-14`）
- ベストは `localStorage` の `chibiupa_best`
- 縦向きだと「よこむきにしてね」を出して自動ポーズ。タッチ抑止はルート CLAUDE.md の方針どおり（`KEEP='button,.menu'`）
- デバッグ用に `window.__game` を公開している
