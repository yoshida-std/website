# ナイフマスター（`games/Knife-Master/`）

「スパルタンX」のナイフ使い（敵キャラ）が主人公の、横スクロールのアクション。**スマホ横画面**向け（縦向きだと「横向きにしてね」を出して止まる）。`index.html` 1枚で完結。画像・音のファイルはなし（絵は canvas で四角を並べて描き、音は WebAudio）。
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/UeZCkVpuqGkjQ72Vqr1w4F`（変更のたびにこの URL を更新する。`index.html` だけを載せる）

## ゲーム内容

- ナイフ使い（青い胴着）を操作して、本当の主人公（白い胴着）をたおす。全5ステージ。**ステージごとに向きが変わる**（本物のゲームで主人公の進む向きが変わるのに合わせる）: 奇数ステージ（1,3,5）は自分が画面左・敵は右から来て左へ進む（画面は左へスクロール）、偶数ステージ（2,4）はその逆（右へスクロール）
- ナイフ使いは **近づかれると弱い**: 敵が 46px 以内だと投げ終わるまで 0.55 秒動けず再装填もおそい（ふだんは 0.3 秒動けず約 0.4 秒で再装填）、敵のパンチ・足払いは 1 ダメージずつの連打、飛び蹴りは 3 ダメージで後ろへ大きく飛ばされる。きょりを取りながら投げるのが基本
- ライフは 10。ステージクリアで +3（最大10）、なくなったらゲームオーバー。1ステージ 99 秒、時間切れもゲームオーバー
- スコア: ナイフ命中 100、ステージクリアで 残り秒数×10 + ライフ×100、全クリアでライフ×300。ベストは `localStorage` の `knifemaster_best`

## 操作

- スマホ: 左の丸いパッド（左半分＝左へ、右半分＝右へ。指をすべらせて切り替え可）、右に「下段ナイフ」「上段ナイフ」（押しっぱなしで連射）、中央下に ポーズ
- キーボード: ←→（A D）いどう、Z / Space / J 上段ナイフ、X / K / ↓ 下段ナイフ、P / Esc ポーズ、Enter でメニューの先頭ボタン
- ナイフは **上段**（胸の高さ。足元から 36px）と **下段**（しゃがんで投げる。足元から 10px）。**投げている間（`P.lock`）は移動不可**
- **ジャンプはない**。自分の向きは **左右キーで決まる**（最後に押した向きのまま。`P.face`）。**敵の方を向いているときだけ** 投げられる（逃げている間は背を向けているので、振り向く＝敵の方へ一歩動く必要がある）。同時に画面にあるのは 3 本まで

- ステージ開始（`intro` 約2.9秒）: 敵は画面の外（x=−75）から歩いて入ってくる（x=30 まで）。その間は操作できない。「STAGE n」→「FIGHT!」

## 仕様のメモ（コード内の定数は `index.html` 冒頭・`cfg(n)`）

- 向きの実装: ゲームの中身（座標・AI）は「自分が右へ逃げる」向きだけで書き、奇数ステージ（`mirror()`）は `draw()` で world を左右反転して描き、左右ボタン・キーの向きも反転している。HUD は反転しない

- 論理サイズ 480×270、地面（足元）は y=212。画面は `max(camX, プレイヤーx − 250)` で（論理上の）右へだけスクロール。プレイヤーは（論理上の）画面端より後ろへ行けない
- 敵の状態: `walk`（近づく。離れると最大2.8倍まで加速して画面から置いていかれない）。56px 以内で攻撃を選ぶ: `combo`（`kind`=`jab` パンチ連打 2〜（1+ceil(ステージ/2)）発、1発 0.27秒、届く 40px、36px 以内のときだけ。`kind`=`sweep` 足払い連打 1〜2発（ステージ3以降は1〜3発）、1発 0.38秒、届く 50px、足元の高さ 0〜9 に当たる。しゃがむので頭の高さ 28 → 上段ナイフが頭上を通る）、`wind`（0.34秒の予備動作）→ `dash`（**真上に飛ぶ飛び蹴り**。その場でジャンプして、落ちながら蹴る。vz<40 かつ高さ44未満・50px 以内なら命中。**3ダメージ＋後ろへ大きく飛ばされる**＝`hurtPlayer(…,heavy)`。無敵 1.4 秒）→ `rest`（0.55秒の隙）。ナイフが近づくと `crouch` か `jump` でよける、ナイフが当たると `hurt`（0.18秒の怯み。怯んだあと 1.4 秒は怯まない）。パンチ・足払いは当たると 0.12 秒のけぞり・無敵 0.2 秒（連打が全部当たる）
- ステージごとの強さ `cfg(n)`: HP 18+5(n−1)、歩く速さ 46+6(n−1)、攻撃の間隔 1.1−0.12(n−1)、よける確率 0.3+0.1(n−1)、ステージ3以降は予備動作〜飛び蹴りの最中は怯まない（`armor`。飛び蹴りは予備動作の間に離れてかわすか、ナイフで止める）。背景の壁の色と帯の色もステージごと
- 当たり判定: プレイヤーは足元〜+44px。パンチは足元+18〜+36、足払いは 0〜9、飛び蹴りは（敵の高さ+6〜+34）。しゃがんで下段を投げているプレイヤーは頭の高さ 30
- ポーズ・画面が隠れる・縦向きになる、のどれかで自動ポーズ（`visibilitychange` では音も止める）
- デバッグ用に `window.__g`（`G`、`inp`、`P`、`E`、`knives`）を出している。Playwright からは `__g.inp.throw=true` のように入力を直接操作できる

## 動作確認のしかた

`python3 -m http.server` で配信して Playwright（例: 844×390、`hasTouch`/`isMobile`）で開く。ボットは `__g.inp` を毎フレーム書き換えて、敵との距離 `|E.x−P.x|` が 125 未満なら右へ、200 超なら左へ、ナイフは連射、にすると全ステージをクリアできる。
