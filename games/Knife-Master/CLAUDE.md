# ナイフマスター（`games/Knife-Master/`）

某有名なカンフーゲームのナイフ使い（敵キャラ）が主人公の、横スクロールのアクション。**スマホ横画面**向け（縦向きだと「横向きにしてね」を出して止まる）。`index.html` 1枚で完結。画像・音のファイルはなし（絵は canvas で四角を並べて描き、音は WebAudio）。
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/UeZCkVpuqGkjQ72Vqr1w4F`（変更のたびにこの URL を更新する。`index.html` だけを載せる）

## ゲーム内容

- ナイフ使い（青い胴着）を操作して、本当の主人公（白い胴着）をたおす。全5ステージ。**ステージごとに向きが変わる**（本物のゲームで主人公の進む向きが変わるのに合わせる）: 奇数ステージ（1,3,5）は自分が画面左・敵は右から来て左へ進む（画面は左へスクロール）、偶数ステージ（2,4）はその逆（右へスクロール）
- **ゲームのルール**: **敵をたおしたらゲームクリア**（どのステージでも。`win()`→`endWin()`）。**敵が階段にたどりついたら（ステージ1〜4）、敵は階段をのぼって扉に消え（`climb()`、`G.state='climb'`）、次のステージへ持ち越し**（自分はそのまま。敵のライフは `G.eHP` で持ち越し、次のステージへ行くときに最大の30%（`EREC`=0.3。約3.6）回復）。**最上階（ステージ5）で敵が女性にたどりついたら負け**（`lose('GOAL')`）。その演出: 敵が女性を救い、**女性が椅子から立ち上がって敵のそばへ歩いて寄り添い、ハートが出る**（`G.cap.rs`、`drawWomanStand`、`drawHeart`。約4秒。自分は倒れない）→ ゲームオーバー（「女性を すくわれてしまった…」）。やられても時間切れでも負け（ゲームオーバー）。ゲーム開始時の敵のライフは `EHP`=12
- 敵のゴールの位置は `goalX()`（階段のステージは `LEN−140`＝階段のふもと、最上階は `LEN−100`＝女性の前）。敵は **いつもゴールへ向かって歩き続ける**（自分が前にいても通りぬける。速さ `cfg().spd`）。自分が敵の後ろにいるときも、そのまま行ってしまうので、振り向いて追いかけて投げる
- ナイフ使いは **近づかれると弱い**: 敵が 46px 以内だと投げ終わるまで 0.55 秒動けず、次を投げられるまで 1.4 秒かかる（ふだんは 0.3 秒動けず、次まで 1.0 秒）、敵の攻撃はどれも1回あたったらアウト。きょりを取りながら投げるのが基本
- **自分は1回あたったらアウト**（`hurtPlayer`）。はね飛ばされて、床も抜けて画面の下へ落ちていく（`P.dead` の間は重力だけで落下）→ ゲームオーバー。**敵にだけライフがある**（HUD の ENEMY バー。全ステージ共通の `EHP`=12 を持ち越し。回復は小数なので、バーは小数の幅になる）。敵のライフがなくなると、敵も後ろへはね飛ばされて床を抜けて画面の下へ落ちていく（`win()`、`E.kbv`）。自分は逃げ足が速い（`SPD`=150）。1ステージ 99 秒、時間切れもゲームオーバー
- スコア: ナイフ命中 100、勝ったとき 残り秒数×10 + （6−そのステージ番号）×1000（早く勝つほど高得点）。ベストは `localStorage` の `knifemaster_best`

## 操作

- **スコア欄はゲーム画面の上に重ねる**（黒い帯なし）。canvas は 480×200、世界を `TOPY=-50` だけ上へずらして描き、HUD（`drawHUD`）は暗いグラデーションの上に画面座標で描く。ゲーム画面を大きくするため、屋根の上の余白と床下の水も詰めてある
- **画面レイアウト**: 横画面を縦に 4:1 に分け、**上 4/5 がゲーム画面（`#stage`。canvas は枠に収まる最大サイズで中央）、下 1/5 がボタンの領域（`#ctl`）**。ボタンの大きさは `vh` 基準（移動パッド高さ 16vh、上段 16vh、下段・ポーズは 14vh 以下）で、領域に収まるようにしてある。ボタンはゲーム画面に重ならない。メニュー（`#overlay`）だけは全体にかぶせる
- スマホ: 左の丸いパッド（左半分＝左へ、右半分＝右へ。指をすべらせて切り替え可）、右に「下段ナイフ」「上段ナイフ」（**連射はできない**。押した瞬間だけ受けつけ、押しっぱなしでは投げない）、中央下に ポーズ（すべて `#ctl` の中）
- キーボード: ←→（A D）いどう、Z / Space / J 上段ナイフ、X / K / ↓ 下段ナイフ、P / Esc ポーズ、Enter でメニューの先頭ボタン
- ナイフは **上段**（胸の高さ。足元から 36px）と **下段**（しゃがんで投げる。足元から 10px）。**投げている間（`P.lock`）は移動不可**
- **ジャンプはない**。自分の向きは **左右キーで決まる**（最後に押した向きのまま。`P.face`）。**ナイフボタンを押すと、敵の方向を自動で向いて投げる**（`tryThrow`）。**ナイフは画面に1本だけ。1本投げたら、次を投げられるまで約1秒かかる**（`P.cd`。投げられない間は2つのナイフボタンが暗くなる）。（飛んでいる間は次を投げられない。投げられない間に押すと 0.25 秒だけ先行入力として覚える）

- **最上階（ステージ5）の裏技**: 自分は女性の後ろまでまわりこめる（自分の移動範囲は全ステージ `LEN−26` まで）。**ナイフは女性にも当たる**（女性の判定は x が `LEN−80`〜`LEN−52`、高さ −2〜44。ナイフはそこで消える）。**1発当てると女性が椅子から画面の下へ飛び出して勝利**（`win(true)`、`G.trick`、`G.cap`）。ゲームクリア画面は「裏技発見！ 女性が ふっとんでいった…」。ゲーム内に説明やカウント表示は出さない（裏技）。当たると火花が出る
- **自機の矢印**（`drawYou`）: 登場演出のとき、自機の頭の上に「YOU」と上下にゆれる黄色い矢印を出す。自機がまだ画面の外にいるときは、画面のはしから向きをしめす矢印と「YOU」を出す。スタートしてからも約1.8秒（最後の0.6秒はまたたく）つづく
- **ステージ開始の演出**（`intro`。止めずに、そのままゲーム開始）: (1) 敵が画面の外（x=−75）から歩いて登場（ゴールへ向かう歩き `cfg().spd` のまま）→ (2) 敵が画面の x=40 まで来たら、**敵に合わせてスクロールがはじまる**（`camX=E.x−40`）→ (3) 開始から1.6秒で**自機が画面の外（`camX+520`）から走って現れ**（速さ `SPD`）、`camX+250` まで来たら **対峙で止めず、そのまま `play` に入る**（敵は歩き続けたまま。「FIGHT!」を0.9秒出す。敵の最初の攻撃は0.8秒後以降）。「STAGE n」（ステージ5は「FINAL STAGE」）は 2.2 秒まで出す。その間は操作できない

## 仕様のメモ（コード内の定数は `index.html` 冒頭・`cfg(n)`）

- 向きの実装: ゲームの中身（座標・AI）は「自分が右へ逃げる」向きだけで書き、奇数ステージ（`mirror()`）は `draw()` で world を左右反転して描き、左右ボタン・キーの向きも反転している。HUD は反転しない

- 論理サイズ 480×200（世界の座標を 50 上へずらして描く）、地面（足元）は世界の y=212。画面は `max(camX, プレイヤーx − 250)` で（論理上の）右へだけスクロール。**スクロールには限界がある**: ステージの長さ `LEN`=900、`camX` の最大は `LEN−480`、自分は `LEN−26`（最上階は `EDGE()`）より先へ行けない（行き止まりで追い詰められる）。**スクロールの最後の背景に、上の階へ行く階段と扉**（`drawBG`。7段で、最上段は奥の扉までつづく踊り場。壁にはめこまれた両開きの扉。手すりつき。敵は踊り場の扉の中へ入って消える）がある。**最上階（ステージ5）だけは階段のかわりに、椅子に座らされた（ひもでしばられた）チャイナドレスの女性**（`drawCaptive`。座った高さは約37px。一回り小さくした）。敵（`EDGE()`）の行き止まりは椅子の手前。ステージ5の開始演出は「FINAL STAGE」。自分は（論理上の）画面端より後ろへ行けない
- 敵の状態: `walk`（ゴールへ向かって歩き続ける）。56px 以内で攻撃を選ぶ: `combo`（`kind`=`jab` パンチ連打 2〜（1+ceil(ステージ/2)）発、予備動作 0.24秒＋攻撃、1発 0.46秒、届く 40px、36px 以内のときだけ。`kind`=`sweep` 足払い連打 1〜2発（ステージ3以降は1〜3発）、予備動作 0.3秒＋攻撃、1発 0.56秒、届く 50px、足元の高さ 0〜9 に当たる。しゃがむので頭の高さ 28 → 上段ナイフが頭上を通る）、`wind`（0.45秒の予備動作）→ `dash`（**真上に飛ぶ飛び蹴り**。その場でジャンプして、落ちながら蹴る。vz<40 かつ高さ44未満・50px 以内なら命中。**当たるとアウト（より大きくはね飛ばされる）**＝`hurtPlayer(…,heavy)`）→ `rest`（0.55秒の隙）。ナイフが近づくと、**上段ナイフにはしゃがみ（`crouch`）、下段ナイフにはジャンプ（`jump`）** でよける（確率はステージごと。足払いの最中もしゃがんでいるので上段は当たらない）、ナイフが当たると `hurt`（0.18秒の怯み。怯んだあと 1.4 秒は怯まない）。1回あたったらアウトなので、攻撃の予備動作を長めにして、見てから離れられるようにしてある
- ステージごとの強さ `cfg(n)`: （敵のライフは `cfg` ではなく `G.eHP`）歩く速さ 110+7(n−1)（ステージ1=110 → ステージ5=138 px/秒。自分は150）、攻撃の間隔 1.1−0.12(n−1)、よける確率 0.2+0.1(n−1)（ステージ1=0.2 → ステージ5=0.6）、ステージ3以降は予備動作〜飛び蹴りの最中は怯まない（`armor`。飛び蹴りは予備動作の間に離れてかわすか、ナイフで止める）。背景の壁の色と帯の色もステージごと
- 当たり判定: プレイヤーは足元〜+44px。パンチは足元+18〜+36、足払いは 0〜9、飛び蹴りは（敵の高さ+6〜+34）。しゃがんで下段を投げているプレイヤーは頭の高さ 30
- ポーズ・画面が隠れる・縦向きになる、のどれかで自動ポーズ（`visibilitychange` では音も止める）
- デバッグ用に `window.__g`（`G`、`inp`、`P`、`E`、`knives`）を出している。Playwright からは `__g.inp.throw=true` のように入力を直接操作できる

## 動作確認のしかた

`python3 -m http.server` で配信して Playwright（例: 844×390、`hasTouch`/`isMobile`）で開く。ボットは `__g.inp` を毎フレーム書き換えて、敵との距離 `|E.x−P.x|` が 125 未満なら右へ、200 超なら左へ、ナイフは1本ずつ（`__g.inp.throw` を押す→離すで投げる。押しっぱなしでは投げない）、にすると全ステージをクリアできる。
