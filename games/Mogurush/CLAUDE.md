# モグラッシュ！（`games/Mogurush/`）

スマホ縦画面向けの次世代モグラ叩き。公開URL: `https://yoshida-std.github.io/website/games/Mogurush/`
リポジトリ全体の作業ルール（ブランチ・PR・確認方法・コピーライト表記）はルートの `CLAUDE.md` を参照。

プッシュ前の確認用 Artifact: `https://claude.ai/artifact/AeGGRoNwxPkYRNhBYXurxk`（変更のたびにこの URL を更新する。`index.html` と `sound/*.mp3` を同じパスで載せる）

## 概要と操作

- 4列×4行の穴からモグラが顔を出して隠れる。顔を出したモグラを **タップ** でたたく
- ときどきモグラが **予告なしに** 穴から飛び出し、穴のすぐ手前に着地して **キョロキョロ** 止まる。その間だけ **フリック** でなぎとばせる（タップは無効で、ぷにっと弾むだけ）
- キョロキョロの時間が切れると画面の外へ走り去り、「にげられた」になる。**5回にげられるとゲームオーバー**
- 全10ステージ。進むほど速く・多く・手ごわくなる
- 特殊なモグラ: ヘルメット（2回たたく、ステージ3〜）、ゴールド（高得点、短時間）、ボム（たたくと減点、ステージ5〜）
- 右上のボタンで一時停止（つづける／音 ON・OFF／最初から／タイトルへ）

## 決めた仕様

**モグラの状態**: `rise → up → hide`（普通のモグラ）／ `rise → jump → look → run`（逃げるモグラ）／ `hit`・`flicked`・`done`

**当たり判定**
- タップ（`pointerdown` 時点で判定）: 状態が rise/up/hide で、出ている割合 `p ≥ 0.25` のモグラ。横は穴の中心から `±L.mw*0.68`、縦は `穴の中心y − L.mh*p − L.mw*0.3` 〜 `穴の中心y + L.ry*1.6`。手前の列から先に判定する
- フリック: 直近90ms の指の動きが 14px 超、かつ速さが 0.4px/ms 超。その線分がモグラの中心（`y − L.mh*0.45`）から `L.mw*0.75+12` 以内なら命中。有効なのは状態が **jump と look のときだけ**
- 地上のモグラ（jump/look/run）へのタップ: 中心から `L.mw*0.8+8` 以内なら弾むだけで効果なし（「フリック！」の吹き出しを1.2秒に1回まで出す）

**スコア**
- 普通 100、ヘルメット 150（1回目は「カン！」で0点）、ゴールド 500、フリック 300
- コンボ倍率 `1 + min(4, floor(combo/5)) × 0.5`（最大 ×3.0）
- コンボが切れる条件: 顔を出したモグラを見逃す（ボムは除く）、にげられる、ボムをたたく
- ボム: −300（スコアは0未満にならない）
- ステージクリアボーナス `ステージ番号 × 200`。1匹もにげられずにクリアすると +1000 と、にげられた回数を1回分回復
- ベストスコアは `localStorage` の `mogurush_best`

**ステージ構成**（`cfg(n)`、k = (n−1)/9）

| 項目 | 式 | ステージ1 → 10 |
|---|---|---|
| 出る総数 | 10 + 3n | 13 → 40 |
| 同時に出る最大数 | min(5, 1+ceil(n/2)) | 2 → 5 |
| 出現間隔(秒) | 0.95 − 0.55k（×0.7〜1.3の揺らぎ） | 0.95 → 0.40 |
| 顔を出す時間(秒) | 1.25 − 0.68k | 1.25 → 0.57 |
| 逃げる確率 | 0.07 + 0.26k（普通のモグラのみ） | 7% → 33% |
| キョロキョロ時間(秒) | 1.5 − 0.8k | 1.5 → 0.7 |
| 走り去る速さ(マス/秒) | 1.6 + 0.18(n−1) | 1.6 → 3.2 |
| ジグザグ | ステージ6から (n−5)×0.17 | — |
| ヘルメット確率 | ステージ3から 0.1 + 0.02(n−3) | — |
| ボム確率 | ステージ5から 0.08 + 0.015(n−5) | — |
| ゴールド確率 | 0.05 | — |

- ステージ1の5匹目は必ず逃げるモグラにして操作を教える（キョロキョロ時間 ×2.5、飛び出しは0.45倍のスロー、画面上部に案内を表示）。最初の1匹が片付くまで続く
- ステージクリア = 総数を出し切り、画面上のモグラが全部いなくなったとき
- 5回目のにげられで約1秒「GAME OVER」を表示してから結果画面

**音**
- ゲーム中は BGM095 をループ（一時停止で止め、再開で続きから）。タイトル画面は無音
- ゲームオーバーで ME003、10ステージクリアで ME007（どちらも BGM を止めて再生）。ステージ1〜9のクリアは BGM を流したまま、合成音のファンファーレ
- 効果音は WebAudio の合成音（`SFX`）。`AudioContext` はスタートボタンを押したときに作る
- 画面が隠れたら一時停止し、`AudioContext` を suspend する

**見た目**: やわらかい水彩風の草原（空・太陽・雲・山・木々・芝のプレート・土の盛り上がった穴）。パネルはクリーム色＋ベージュの枠。絵はすべて canvas のコードで描いていて、画像ファイルは使っていない

## ファイル構成と役割

```
games/Mogurush/
├── CLAUDE.md               … このファイル
├── index.html              … ゲーム本体（HTML / CSS / JS をすべて含む）
└── sound/
    ├── bgm095.mp3          … ゲーム中BGM（元: BGM095-100811-minnnaatsumare.wav, 36秒）
    ├── me003_gameover.mp3  … ゲームオーバー（元: ME003-090129-sleap01.wav）
    └── me007_allclear.mp3  … 10ステージクリア（元: ME007-090401-clear03.wav）
```

`index.html` 内の主な区分（`/* ---------- ... ---------- */` のコメントで区切っている）

- ブラウザ動作の抑止 … touchstart などの preventDefault（`button` と `.scrollable` は除外）
- 音 … `initAudio` / `tone` / `noise` / `SFX`、BGM・ME（`MUSIC`, `startBgm`, `pauseBgm`, `stopBgm`, `playMe`）
- レイアウト … `layout()` で盤面サイズと穴の位置を計算（`L.cw`, `L.ch`, `L.rx`, `L.ry`, `L.mw`, `L.mh`）。`renderBg()` で背景を別 canvas に描いておく
- ステージ設定 … `cfg(n)`, `INTRO`
- ゲーム状態 … `G`, `spawn`, `startJump`, `bonk`, `boom`, `flick`, `escape`, `missed`
- 更新 … `update`, `updMole`
- 描画 … `drawMole`, `drawBomb`, `drawInHole`, `drawHoleFront`, `drawOut`, `draw`, `drawTrails`
- 入力 … `tap`、canvas の `pointerdown` / `pointermove`（フリック判定）
- HUD・画面 … `updHud`, `showTitle`, `stageClear`, `gameOver`, `pause`, `resume`, `toggleMute`

## 未完成のところ・既知のバグ

- **実機で未確認**: フリックの感度、難易度のバランス、BGM のループのつなぎ目（MP3 の末尾の無音を避けるため `BGM_LEN=36.0` を `loopEnd` にしている。Safari で小さな切れ目が出るかも）
- 画面サイズが変わったとき、地上にいるモグラの座標を新しいサイズに合わせていない（少しずれるだけ）
- ステージ1の練習で、最初の1匹が片付く前に次の逃げるモグラが出ると、そちらも練習扱い（スロー＋案内）になる
- 音の ON/OFF はページを読み込み直すと ON に戻る（保存していない）
- canvas の文字は Google Fonts の読み込みが終わるまで代わりのフォントで表示される
- 一時停止中に音を ON/OFF すると、メニューを描き直すために一度だけ一時停止を解除して戻している（見た目の変化はない）

## やらないと決めたこと

- 飛び出しの予告（赤い目・「！」・警告音）と、予告中にたたく「セーフ」ボーナスは廃止した
- 走り去っている途中（run）のモグラはフリックでも止められない。地上のモグラはタップでは一切倒せない
- にげられた回数はステージをまたいで持ち越す（リセットしない）。回復は1匹もにげられずにクリアしたときの1回分だけ
- タイトル画面では音を鳴らさない
- 元の WAV はリポジトリに入れない（MP3 に変換したものだけを置く）
- 最初のネオン調のデザインはやめて、水彩風の草原デザインにした
- 画像素材・外部ライブラリ・ビルド工程は使わない（Google Fonts だけ読み込む）
